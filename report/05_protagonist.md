# 第5章　主人公類型学 ―― 誰が、なぜ、異世界へ行くのか

> **本章の要点**
> WEB小説の主人公は、伝統的な意味での「人物造形」よりも、**読者の代理装置**としての機能が優先される。だが「没個性」というのは分析としては雑である。実際には、転生前の属性、能力の由来、性格の類型、価値観の出所という四つのレイヤーで、精密な設計がなされている。本章はそれを解剖する。

---

## 5-1　主人公は「誰」ではなく「どこ」である

### 代理装置としての主人公

WEB小説の主人公には、しばしば次のような特徴がある。

- 外見の描写が乏しい（あるいは平凡と明示される）
- 前世の名前が明かされない、または途中で忘れられる
- 内面の葛藤が薄く、行動の動機が単純

これは伝統的な小説作法から見れば欠点である。しかし機能から見ると別の姿が現れる。**主人公は「読者が入る器」として設計されている**。描写が薄いのは、読者の自己投影を妨げないためである。

ただし、ここで注意が必要だ。**すべてのWEB小説の主人公が空の器なのではない**。むしろ、長く支持される作品ほど主人公に固有の欠落と傾向がある。『無職転生』のルーデウスは、前世の無為への強烈な後悔と、性的な欲望と、家族への希求という、明確に個別的な人物である。『Re:ゼロ』のスバルは、無能で、空回りし、自己嫌悪に沈む。

したがって正確な定式化はこうなる。

> **短期的な人気には「空の器」が有利だが、長期的な支持と作品の記憶には「固有の欠落」が必要である。**

初速のために器を用意し、持続のために欠落を与える。両立させるのが上級の設計である。

### 二種類の同一化

読者が主人公に対して行う同一化には、二つの異なる型がある。

| 型 | 内容 | 適した作品 |
|---|---|---|
| **憑依型** | 読者が主人公になる。主人公の判断＝読者の判断 | 無双もの、スローライフ、VRMMO |
| **観察型** | 読者は主人公を外から見て応援する。主人公は他者 | 勘違い系、悪役令嬢、群像劇 |

勘違い系が視点を切り替えるのは、読者を観察型に置くためである。逆に、憑依型の作品で主人公の視点を離れると、没入が壊れる。**自作がどちらの型かを自覚することは、視点設計の前提になる。**

## 5-2　転生前の属性カタログ

主人公が異世界に来る前に何者だったか。この設定は、単なる背景ではなく、**主人公が持ち込む資源**を規定する。

| 前世の属性 | 持ち込む資源 | 読者への効果 | 使用頻度 |
|---|---|---|---|
| **社畜・ブラック企業勤務** | 忍耐力、事務処理能力、「もう働きたくない」動機 | 強い共感。スローライフへの説得力 | 非常に多い |
| **高校生・大学生** | 若さ、現代の一般教養、ゲーム知識 | 若年読者の同一化 | 多い |
| **ひきこもり・無職** | 後悔、時間、ネットで得た雑多な知識 | やり直しの物語に直結 | 多い |
| **老人・寿命死** | 人生経験、達観、孫世代への愛着 | 落ち着いた語り、癒し系と相性良 | 中程度・近年増加 |
| **専門職（医師・薬剤師・研究者）** | 具体的で強力な知識チート | 説得力の高い無双。作者の実知識が活きる | 中程度 |
| **職人・料理人・農家** | 技能。生産系の中核 | 過程の描写が面白い | 中程度 |
| **軍人・自衛官・警察官** | 戦闘技能、組織運用能力 | 戦記・国防ものに直結 | 少数だが根強い |
| **主婦・母親** | 生活知、育児、家事。女性向けに多い | 生活描写の説得力 | 女性向けで中程度 |
| **オタク・ゲーマー** | 作品知識、メタ的視点 | 原作知識チートの前提 | 悪役令嬢等で必須 |
| **前世なし（現地人）** | なし | 世界への没入。ただし共感の足場が要る | 少数 |
| **前世の記憶が途中で戻る** | 遅延した資源投入 | 物語中盤での転換装置 | 女性向けに多い |

### 設計上の要点

**（1）前世は「動機の供給源」である。**
社畜だったから休みたい。無職だったからやり直したい。医者だったから救いたい。**前世設定は、主人公が異世界で何を欲するかを、説明なしに正当化する**。

**（2）前世は「技能の正当化装置」である。**
主人公が唐突に高度な知識を持っていても、「前世で薬剤師だった」の一行で許容される。逆に言えば、**前世設定と噛み合わない知識は違和感を生む**。社畜だった主人公が突然、冶金学を語り出すのは説得力が弱い。

**（3）前世は「読者の現在」である。**
社畜・学生・無職という頻出属性は、そのまま読者層の自画像である。**主人公の前世は、読者が逃れたい現実の圧縮された表現**として機能している。

## 5-3　能力獲得の設計

### 獲得経路の類型と、それぞれの物語効果

| 経路 | 具体例 | 物語上の効果 | リスク |
|---|---|---|---|
| **女神・神からの授与** | 「お詫びにチートを差し上げます」 | 導入が最速。理由を問われない | 安易に見える。物語的責任が薄い |
| **システムからの付与** | ステータス、スキル、ジョブ | 数値管理ができる。成長を可視化できる | 世界のルール設計が必要 |
| **外れスキルの再解釈** | 「鑑定」が実は万能、「調合」が実は錬成 | 追放ものの標準。**評価の反転そのものが快楽** | 都合の良さが目立ちやすい |
| **前世知識** | 医学、農学、製鉄、経営 | 説得力が高い。作者の勉強が活きる | 考証の甘さが露呈する |
| **原作知識** | ゲームの攻略情報 | 未来を知る最強のアドバンテージ | 知識の有効期限が切れると失速 |
| **血統・種族** | 竜の血、魔族、聖女の家系 | 世界の設定と統合しやすい | 「生まれつき」なので成長の物語になりにくい |
| **修行・努力** | 地道な鍛錬 | 成長のカタルシスが最大 | 序盤が遅い。WEB連載では不利 |
| **契約・代償** | 悪魔契約、寿命の代価 | 緊張感が生まれる | ストレス要因になる |
| **道具・遺物** | 神器、古代兵器 | 奪われる・壊れるという展開が作れる | 主人公自身の価値が薄まる |

### 「外れスキル」というイノベーション

追放ものが発明した最大の装置が「**外れスキル**」である。

```
①主人公は一見無価値なスキルを持つ（例：「収納」「鑑定」「調合」「支援」）
②周囲はそれを理由に主人公を軽視する
③実は、そのスキルには誰も気づいていない用途がある
④用途が明らかになった瞬間、主人公の評価と物語が反転する
```

この構造の優れている点は、**チートの授与という「棚ぼた」を、発見という「主体的行為」に変換している**ことである。読者は「神様に貰った」よりも「自分で気づいた」ほうが、はるかに正当な報酬と感じる。

さらに、外れスキルは**評価の反転そのものが快楽である**という点で、ざまぁ構造と完全に噛み合う。追放ものが爆発的に増殖した技術的な理由は、ここにある。

### 能力設計の三原則

**原則1：能力には制約を設ける。**
無制限の万能能力は、あらゆる問題を消してしまう。制約（回数、時間、範囲、代償、条件）があるからこそ、工夫の余地と緊張が生まれる。

**原則2：能力の「面白い使い方」を先に考える。**
「時間停止」という能力そのものは平凡だが、それを使って何をするかが作品の個性になる。**能力名ではなく用途で差別化する。**

**原則3：能力は世界観と結びつける。**
なぜその能力が存在するのか、他の人はなぜ持っていないのか。この説明が世界設定と接続していると、能力が「作者の都合」ではなく「世界の必然」に見える。

## 5-4　性格の類型

WEB小説の主人公には、いくつかの反復される性格類型がある。それぞれが異なる物語効果を持つ。

### ① 無自覚・鈍感型
自分の異常さに気づいていない。周囲の驚愕と本人の平静のギャップが笑いを生む。

- **効果**：勘違い系の中核。読者だけが真相を知る優越感
- **注意**：鈍感が「不誠実」に見える閾値がある。とくに恋愛感情への鈍感は、長引くと読者の苛立ちを生む

### ② 達観・老成型
前世の年齢や経験から、若い体で年長者の判断をする。

- **効果**：落ち着いた語り。周囲への保護者的な視線
- **注意**：葛藤が生まれにくい。物語の駆動力を別に用意する必要

### ③ 善良・お人好し型
困っている者を放っておけない。結果として仲間と信頼を集める。

- **効果**：仲間が増える構造の正当化。読者の道徳的な安心
- **注意**：能動性が弱くなりがち。「巻き込まれ続ける」構造になりやすい

### ④ 合理・冷徹型
感情ではなく効率で判断する。必要なら非情な選択もする。

- **効果**：知的な満足。予測不能性
- **注意**：共感の維持が難しい。**冷徹な主人公には、必ず「守るもの」を与える**のが定石

### ⑤ 欲望駆動型
金、地位、女性、快楽、あるいは「本を読みたい」といった具体的な欲望が行動を決める。

- **効果**：**動機が明快で、物語が自走する**。長期連載に強い
- **注意**：欲望の種類によって読者を選ぶ

### ⑥ 逃避・非競争型
争いたくない、目立ちたくない、静かに暮らしたい。

- **効果**：スローライフ系の中核。現代読者の願望に直結
- **注意**：物語が止まる。**外部からの干渉を定期的に入れる**必要

### ⑦ 陰気・自己評価低型
自分の価値を認められない。称賛されても信じない。

- **効果**：称賛の受領が繰り返し使えるエンジンになる
- **注意**：卑屈さが過剰だと読者が疲れる

### ⑧ 中二病・演技型
理想の自分を演じる。演技が現実になってしまう。

- **効果**：メタ的な笑いと、格好よさの両立
- **注意**：作者の照れが出ると失敗する。**徹底することが条件**

### ⑨ 職人・探究型
特定の対象への集中的な関心。周囲より対象を優先する。

- **効果**：生産系・研究系の駆動力。専門描写に説得力
- **注意**：人間関係が薄くなる

### ⑩ 保護者・育成型
子ども、従魔、部下を育てることに充足を見出す。

- **効果**：近年の癒し系需要に合致。成長の物語を他者に委託できる
- **注意**：主人公自身の成長が止まる

> **実務的なアドバイス**：これらは排他的ではなく、**二つを組み合わせる**と個性が生まれる。「達観 × 欲望駆動」（落ち着いているが本を読むことには執着する）、「善良 × 冷徹」（優しいが必要なら切り捨てる）など。三つ以上組み合わせると、輪郭がぼやける。

## 5-5　主人公の価値観 ―― 現代倫理という「隠れたチート」

WEB小説の主人公が持ち込む最大の武器は、実はスキルでも知識でもなく、**現代的な価値観**である。

- 奴隷制を否定する
- 身分による差別を疑う
- 女性・子ども・弱者を守る
- 拷問・処刑を忌避する
- 衛生と教育を重視する
- 労働環境を改善する

これらは異世界の住人にとって新奇な発想であり、主人公はそれを実践することで、**戦闘力とは別の次元で「格の高い存在」として認識される**。

### この装置の構造的な意味

**（1）道徳的優位が承認の源泉になる。**
主人公は強いだけでなく「正しい」。この二重性が、読者の同一化を強化する。単に強いだけの主人公より、正しくて強い主人公のほうが、自己肯定の材料として優れている。

**（2）ただし、しばしば無批判である。**
現代日本の価値観を絶対的な正解として、異世界の制度を裁く構図は、批評的には**文化帝国主義的だという指摘**を受けてきた。奴隷を買って解放する主人公は、奴隷制を利用しつつ道徳的優越も得ている、という二重取りの構造を持つ。

**（3）優れた作品は、この摩擦を扱う。**
現代倫理をそのまま持ち込めば軋轢が生じる。その軋轢を描くか、無視するかで、作品の深度が変わる。『本好きの下剋上』が高く評価される理由の一つは、主人公の現代的価値観が身分社会と衝突し、**しばしば主人公のほうが折れる**という点にある。

> **創作への含意**：現代倫理は使ってよい。ただし「なぜこの世界にはその倫理がないのか」を一度は考えること。理由（資源の不足、魔物の脅威、宗教）があれば、世界に厚みが出る。理由なしに「遅れているから」とすると、世界が主人公を引き立てるための書き割りになる。

## 5-6　インフレ管理 ―― 「最強」をどう持続させるか

主人公最強ものの最大の技術的課題が、**パワーインフレ**である。

### インフレの発生機構

```
強敵を倒す → 読者が満足 → 次はもっと強い敵が必要 → 主人公も強化 →
→ より強い敵が必要 → …（指数関数的な拡大）
```

やがて「神を殺す」「宇宙を破壊する」段階に達し、それ以上の緊張が作れなくなる。

### 六つの対処法

| 手法 | 内容 | 例・注意 |
|---|---|---|
| **① 質的な障害への転換** | 力で解決できない問題を出す（政治、感情、倫理、経済） | 最も上等。ただし読者の期待とずれるリスク |
| **② 守る対象の増加** | 主人公は強いが、守るものが増えて手が回らない | 緊張を維持しつつ強さを保てる |
| **③ 相手の変更** | 個人 → 組織 → 国家 → 世界と、規模で更新する | 定番。ただし燃料はいつか尽きる |
| **④ 制約の追加** | 力を使えない状況、使ってはいけない状況 | 一時的だが効果的 |
| **⑤ 力の外部化** | 主人公ではなく部下・弟子が戦う | 育成もの・組織ものへの移行 |
| **⑥ 目的の非戦闘化** | 戦闘から内政、生産、探究へ主軸を移す | 長期連載の常套。エンジン交代（→第4章） |

**実務的な結論**：①〜⑥のうち、**②と⑥の併用**がもっとも安定する。すなわち「主人公は強い。だが守るものが増え、戦闘以外の課題が主戦場になる」という形である。多くの長寿作品はこの形に落ち着いている。

## 5-7　欠落と成長 ―― 「テンプレを超える」ための唯一の道

本章の最後に、もっとも重要な論点を置く。

無双、ざまぁ、チートといったテンプレは、読者を集める。だが、**読者の記憶に残り、十年後にも語られる作品**は、必ず主人公に**固有の欠落**を持っている。

- ルーデウス（『無職転生』）：前世で何一つ成し遂げなかったことへの、消えない恥辱
- ナツキ・スバル（『Re:ゼロ』）：何の取り柄もない自分への嫌悪と、それでも認められたい渇望
- マイン／ローゼマイン（『本好きの下剋上』）：本を読みたいという、身分社会では叶わない欲望
- アインズ（『オーバーロード』）：仲間を失った孤独と、演じ続けなければならない王の役

これらはすべて、**チートでは埋まらない欠落**である。強くなっても、金持ちになっても、称賛されても、その穴は塞がらない。だからこそ物語が続き、読者が主人公を人間として記憶する。

> **設計上の指針**
> 主人公に、**能力では解決できない欠落**をひとつ与えること。
> それは前世の後悔でもよいし、家族への希求でもよいし、決して手に入らないものへの渇望でもよい。
> 重要なのは、**その欠落が、物語の快楽エンジンとは別の次元にある**ことである。
> エンジンが読者を連れてくる。欠落が読者を離さない。

## 5-8　女性向け主人公の類型

女性向け作品の主人公には、男性向けとは異なる設計原理が働く。

| 類型 | 特徴 | 快楽の所在 |
|---|---|---|
| **転生悪役令嬢** | 破滅の運命を知っている。回避に奔走 | 知識アドバンテージ＋勘違いによる好感度上昇 |
| **虐げられ令嬢** | 家族・婚約者から不当な扱い。忍従から救済へ | 救済と受容。「わかってくれる人」の出現 |
| **有能令嬢** | 実務能力（経営、薬学、内政）で価値を証明 | 正当な評価、自己実現 |
| **聖女・治癒者** | 助ける力で承認を得る | 感謝される快感。攻撃せずに勝つ |
| **モブ・脇役** | 目立ちたくないのに巻き込まれる | メタ的観察、意図せぬ影響力 |
| **前世記憶持ちの一般人** | 現代知識で異世界の生活を改善 | 生活の充実、小さな成功の積み重ね |
| **強かな令嬢** | 打算的、politically有能、感情に流されない | 知略の快感 |
| **自立志向型** | 恋愛より事業・研究・友情を優先 | 2020年代に伸長。選択の主体性 |

### 男性向けとの構造的な差

**（1）「承認」の形が違う。**
男性向けの承認は主として**能力への称賛**（すごい、強い）であるのに対し、女性向けの承認は**存在への受容**（あなたでいい、あなたがいい）に比重がある。溺愛系が成立するのはこの原理による。

**（2）関係性が報酬である。**
男性向けでは関係性はしばしば戦力・拠点として機能するが、女性向けでは関係性の変化そのものが物語の目的である。

**（3）忍従の扱いが繊細。**
虐げられ期間は感情移入を作るが、長すぎると耐えられない。近年は**忍従の圧縮**が進み、第1〜3話で救済者が現れる構成が主流化している。

- [ ] 性格類型を**二つ**組み合わせて輪郭を作っているか
- [ ] 現代倫理を使うなら、「なぜ異世界にはそれがないか」を考えたか
- [ ] インフレへの対処法（②守る対象の増加／⑥目的の非戦闘化）を用意しているか
- [ ] **能力では解決できない欠落**を、ひとつ与えているか
