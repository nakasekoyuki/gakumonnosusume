# 付録C　テンプレ構造カタログ ―― 27の物語型

> 各型を「構造式」として記述した。記号の意味は次の通り。
>
> - `→` 順序（時系列）
> - `⇄` 交互に反復
> - `[ ]` 段階の名称
> - **エンジン**＝繰り返し供給される快楽（→第4章4-4）
> - **燃料**＝そのエンジンが消費するもの
>
> 使い方：①自作に近い型を探す ②その型の「注意点」を点検する ③別の型と組み合わせる（→第3章3-6）

---

## I　男性向け・基幹型

### 01　異世界転生チート
```
[死] → [女神との面会・能力付与] → [転生] → [能力の確認] →
[街への到達] → [冒険者登録] → [実力の露見] ⇄ [称賛の連鎖]
```

- **エンジン**：無双＋称賛　**燃料**：主人公を知らない人物、未見の強敵
- **要点**：能力名ではなく「使い方」で差別化する
- **注意**：最も飽和した型。単独では戦えない。他の型と必ず組み合わせる

### 02　異世界転移サバイバル
```
[突然の転移] → [生存の危機] → [知恵と現代知識で凌ぐ] →
[最初の人間との接触] → [社会への参入] → [帰還か定住かの選択]
```

- **エンジン**：生存の緊張＋工夫の快感　**燃料**：未知の環境要素
- **要点**：現代の道具・知識を「持ち込めるもの」として設計する
- **注意**：序盤の緊張が終わると失速しやすい。定住後の目的を先に決める

### 03　追放ざまぁ
```
[不当な追放] → [双方の運命の分岐] ⇄ [主人公の上昇／追放側の凋落] →
[露見：加害者が失ったものを知る] → [拒絶]
```

- **エンジン**：ざまぁ＋承認　**燃料**：侮る者、比較の機会
- **要点**：追放の理由に「一応の合理性」を持たせる。主人公は復讐しない
- **注意**：ざまぁは持続力が弱い。50話以内に第二のエンジンへ移行する

### 04　追放 → スローライフ
```
[追放] → [辺境への移住] → [小さな生活の構築] ⇄ [訪れる人との交流] →
[時折の外部干渉] → [かつての組織からの懇願と拒絶]
```

- **エンジン**：ざまぁ（導入）→ 癒し・蓄積（持続）　**燃料**：訪問者、季節、作物
- **要点**：**引き込みと持続の分業**の教科書的な形（→第3章3-6）
- **注意**：完全に平穏になると読まれなくなる。小さな波を定期的に

### 05　外れスキルの再解釈
```
[無価値と評価される能力] → [軽視・追放] → [能力の別用途を発見] →
[圧倒的な有用性の証明] ⇄ [新しい使い方の発見の連続]
```

- **エンジン**：発見＋評価の反転　**燃料**：能力の未発見の用途
- **要点**：能力の用途を先に10個考えてから、能力名を決める
- **注意**：用途が尽きると終わる。深さのある能力を選ぶ（「鑑定」「収納」「複製」は深い）

### 06　人外転生・進化
```
[最弱の生物として転生] → [捕食・戦闘による成長] → [進化] ⇄
[新形態での新たな課題] → [知性体との接触] → [社会・勢力の形成]
```

- **エンジン**：成長曲線＋収集　**燃料**：進化先、獲得可能な能力
- **要点**：独白の質が作品の質になる。言語を得るタイミングが構成上の分岐点
- **注意**：人型になると普通の異世界ものに合流してしまう。差異を維持する工夫を

### 07　内政・国づくり
```
[荒廃した土地の獲得] → [問題の診断] → [現代知識による改善] →
[数値の上昇（人口・収穫・税収）] ⇄ [外部からの干渉・妨害] → [防衛と拡大]
```

- **エンジン**：蓄積＋設計の快感　**燃料**：未解決の社会問題、未開発の技術
- **要点**：**数字を見せる**。成長を可視化しないと快感が生まれない
- **注意**：既存産業の反発を描くと厚みが出る。摩擦なき改革は退屈

### 08　生産職・職人
```
[非戦闘職として軽視される] → [技術の実演] → [驚愕] ⇄
[新しい製法・製品の開発] → [工房・商会の設立] → [産業への波及]
```

- **エンジン**：職人的満足＋承認　**燃料**：作れるものの種類
- **要点**：**過程の描写が本体**。結果だけ書くと機能しない
- **注意**：作者の実知識が最も問われる。調べずに書くと薄い

### 09　テイマー・従魔
```
[最初の一匹との出会い] → [契約・信頼の形成] → [育成] ⇄
[新しい仲間の獲得] → [群れ・拠点の形成] → [従魔たちとの別離／継承]
```

- **エンジン**：収集＋愛着　**燃料**：まだ見ぬ生物
- **要点**：一匹ごとに明確な個性を。言葉を話すか否かで関係の質が変わる
- **注意**：数が増えると個々が薄まる。中核3匹＋外周という階層化を

### 10　ダンジョン攻略
```
[迷宮への挑戦] → [階層の踏破] ⇄ [新しい脅威・仕掛け・発見] →
[深層の秘密] → [迷宮の正体]
```

- **エンジン**：攻略の進捗＋未知の踏破　**燃料**：階層、仕掛け、モンスター
- **要点**：階層ごとに新要素を。「深い＝強い」以外の価値軸を並走させる
- **注意**：単調化しやすい。地上パート（人間関係、経済）との交互配置が有効

### 11　ダンジョン経営・マスター側
```
[ダンジョンの主となる] → [構造の設計] → [侵入者の撃退] ⇄
[資源の獲得と拡張] → [外部勢力との交渉] → [共存または征服]
```

- **エンジン**：設計＋防衛の緊張　**燃料**：侵入者、拡張の余地
- **要点**：シミュレーションゲーム的な快感。制約（資源、面積、コスト）が面白さを作る
- **注意**：主人公が動けない設定だと物語が閉じる。外に出る手段を用意

### 12　VRMMO
```
[ゲームへのログイン] → [システムの理解] → [システムの穴の発見] ⇄
[想定外のプレイによる評価] → [運営・他プレイヤーとの関係] → [現実との接続]
```

- **エンジン**：ルールの逆用　**燃料**：システムの未探索領域
- **要点**：**「誰も試さなかったこと」を試す**のが快楽の核
- **注意**：現実側をどれだけ描くかで作品の性格が決まる。全部ゲーム内だと異世界ものと同じに

### 13　学園・隠された実力
```
[能力を隠しての入学] → [侮り] → [事件] → [やむを得ない実力行使] →
[部分的な露見] ⇄ [別の相手・別の場面での反復] → [完全な露見]
```

- **エンジン**：正体露見の快感　**燃料**：まだ知らない人物
- **要点**：露見を**小出しに、毎回別の相手に**。一気に露見させると終わる
- **注意**：なぜ隠すのかの動機が弱いと、行動が不自然になる

### 14　勘違い・すれ違い
```
[主人公の意図] ≠ [周囲の解釈] → [誤解にもとづく好結果] ⇄
[誤解の拡大] → [誤解の上に築かれる地位] → [解消または永続]
```

- **エンジン**：優越的な観察＋笑い　**燃料**：ズレを維持できる状況
- **要点**：**他者視点の挿話が必須**。これなしには成立しない
- **注意**：ズレが解消されると終わる。解消を遅らせる仕掛けを構造に組み込む

### 15　現代ダンジョン成り上がり
```
[ダンジョン出現後の日常] → [能力の覚醒] → [探索者としての登録] →
[ランクの上昇] ⇄ [報道・SNSによる可視化] → [組織・企業との関係] → [世界規模の脅威]
```

- **エンジン**：無双＋可視化された承認　**燃料**：ランク、報道、未踏の階層
- **要点**：**社会制度の設計が説得力を生む**（法、税、保険、教育、報道）
- **注意**：現代を舞台にする以上、整合性の要求水準が高い

### 16　配信・実況
```
[配信の開始] → [視聴者の反応] ⇄ [規格外の行為とコメントの驚愕] →
[認知の拡大] → [現実世界への影響] → [正体の露見]
```

- **エンジン**：可視化された承認　**燃料**：視聴者、記録更新
- **要点**：コメントの書き分けが技術の要。**第三者の反応が本体**
- **注意**：コメント欄の描写が単調だと飽きる。個性ある常連視聴者を作る

### 17　復讐・ダーク
```
[喪失・裏切り] → [力の獲得] → [計画] ⇄ [段階的な報復] →
[目的達成後の空虚] → [再生または破滅]
```

- **エンジン**：抑圧された攻撃性の解放　**燃料**：復讐対象
- **要点**：主人公が能動的に手を汚す点で、通常のざまぁと異なる
- **注意**：読者を選ぶ。タグでの明示が必須。ランキング上位は狙いにくいが濃い読者がつく

### 18　旅・グルメ・遍歴
```
[旅の開始] → [新しい土地] ⇄ [その土地の問題・食文化・人物] →
[解決と別れ] → [次の土地] → [旅の終着点]
```

- **エンジン**：発見＋一話完結の満足　**燃料**：土地、料理、人物
- **要点**：一話完結性が高く、離脱しても復帰しやすい
- **注意**：全体の目的が弱いと、いつまでも続いて終われない

## II　女性向け・基幹型

### 19　悪役令嬢・破滅回避
```
[前世の記憶の覚醒] → [自分が悪役令嬢だと知る] → [破滅エンドの認識] →
[回避行動] ⇄ [空回りと好感度の上昇] → [破滅の回避] → [新しい関係の獲得]
```

- **エンジン**：勘違い＋溺愛＋知識アドバンテージ　**燃料**：攻略対象、イベント
- **要点**：**「知っているのに変えられない」緊張**を維持する装置（強制力、原作補正）を
- **注意**：回避が容易すぎると、ただ好かれる話になる

### 20　婚約破棄・断罪ざまぁ
```
[公衆の面前での婚約破棄] → [令嬢の退場] → [令嬢が支えていた事実の露呈] →
[相手方の凋落] ⇄ [令嬢の新天地での評価] → [謝罪と拒絶]
```

- **エンジン**：ざまぁ＋正当な評価の回復　**燃料**：加害者の失うもの
- **要点**：**第1話に第1段階と第2段階を圧縮できる**。短編・中編と相性が極めて良い
- **注意**：元婚約者を愚か者にしすぎると、ヒロインの評価まで下がる

### 21　追放令嬢・虐げられ系
```
[家族・婚約者からの冷遇] → [追放または出奔] → [救済者との出会い] →
[価値の発見と承認] ⇄ [溺愛] → [過去との対峙] → [自らの選択]
```

- **エンジン**：救済＋受容　**燃料**：新しい環境の人々
- **要点**：**忍従期間は短く**。近年は第1〜3話で救済者を出す構成が主流
- **注意**：受け身のままだと物語が停滞する。ヒロインの能動性をどこかで立てる

### 22　聖女・職能もの
```
[特別な力を持つが正当に扱われない] → [偽物との対比] → [別の場所での評価] →
[能力による貢献] ⇄ [感謝の受領] → [元の場所の困窮] → [呼び戻しと拒絶]
```

- **エンジン**：能力による承認＋感謝　**燃料**：救うべき人々
- **要点**：**戦闘ではなく「助ける」ことで無双する**という女性向け特有の力の形
- **注意**：偽聖女を単純な悪にしない。事情を与えると深みが出る

### 23　溺愛・執着
```
[理由のわからない強い好意] → [戸惑い] ⇄ [献身と距離の縮小] →
[執着の理由の判明（前世、幼少期、運命）] → [受容と関係の確定]
```

- **エンジン**：無条件の受容　**燃料**：好意の表現の種類
- **要点**：**理由の開示が最大の山**。前半で理由を明かさない構成が定石
- **注意**：好意の理由が薄いと、単なる都合の良さになる

### 24　契約結婚・政略結婚
```
[利害による結婚] → [互いへの無関心] → [共同生活での発見] ⇄
[信頼の蓄積] → [契約の枠が邪魔になる瞬間] → [枠の破棄と選択]
```

- **エンジン**：関係の変化そのもの　**燃料**：二人の未知の側面
- **要点**：**契約という枠が距離を管理する装置**。枠がなくなる瞬間を最大の山に
- **注意**：外部からの障害（家、政治）を用意しないと二人だけの話になる

### 25　モブ・脇役転生
```
[主要人物でない立場への転生] → [目立たない方針の決定] →
[意図せぬ介入] ⇄ [物語の変質] → [主要人物からの注目] → [新しい役割の獲得]
```

- **エンジン**：メタ的観察＋巻き込まれ　**燃料**：原作の展開、主要人物
- **要点**：**「目立ちたくない」という明確な欲求**が物語を駆動する
- **注意**：主人公が受動的になりやすい。能動的な目的を別に与える

### 26　後宮・宮廷謎解き
```
[閉鎖社会への参入] → [事件・毒・陰謀] → [知識による解明] ⇄
[身分の上昇と敵の増加] → [権力構造の核心] → [立場の確立]
```

- **エンジン**：知的満足＋身分上昇　**燃料**：事件、宮廷の人々
- **要点**：**風俗の考証**（衣・食・儀礼）が評価を左右する
- **注意**：謎解きの質が問われる。ミステリとしての最低限の作法を守る

### 27　ループ・やり直し（女性向け）
```
[処刑・死別・破滅] → [時間の巻き戻し] → [知識を使った改変] ⇄
[変わるものと変わらないもの] → [根本原因の発見] → [運命の書き換え]
```

- **エンジン**：知識アドバンテージ＋喪失の回復　**燃料**：改変可能な事象
- **要点**：**何を変えられ、何を変えられないか**のルール設計が肝
- **注意**：ループの回数が増えると読者が混乱する。回数を絞る

## IV　この表の正しい使い方

1. **自作に近い型を一つ選ぶ**。完全に一致しなくてよい
2. その型の**「注意」を点検する**。多くの失速はここに書かれた原因で起きる
3. **持続に強い型を一つ足す**。導入型だけでは50話が限界
4. **六成分（→第3章3-2）のうち一つを、標準からずらす**
5. ずらした一点を、**タイトルとあらすじに書く**

型に従うことは、独創性の放棄ではない。**型に従ったうえで、どこを外すかを意識的に選ぶこと**が、実務としての独創である。
