# 付録E　参考情報源と調査上の注記

## E-1　本レポートの成立事情

本レポートは、日本語圏のWEB小説（「小説家になろう」を中心とする投稿サイト群）について、公開情報および広く流通している言説を整理・分析した**二次的なサーヴェイ**である。

### 調査環境の制約（重要）

作成環境において、外部ウェブサイトへの直接アクセスは大きく制限されていた。具体的には、

- **投稿サイト本体（syosetu.com 等）へのアクセスは遮断されていた**
- **Wikipedia等の参照サイトへの直接アクセスも遮断されていた**
- 利用できたのは検索エンジン経由の**要約情報**のみであった

したがって、本レポートは次の性質を持つ。

| できたこと | できなかったこと |
|---|---|
| 傾向・構造の分析と体系化 | ランキングの一次データの照合 |
| 広く共有された知識の整理 | 各年の順位表の網羅的確認 |
| 作品構造の類型化 | 発行部数・ユーザー数の公式確認 |
| 創作技法への変換 | 個別作品の本文にあたっての精読 |

### 数値・年代の扱いについて

**本レポートに記載した年代・順位・部数などの具体的数値は、すべて「おおよその目安」である。**

- 連載開始年と書籍化年は、資料により1〜2年前後することがある
- 「〜年頃」と記した箇所は、とくに不確実性が高い
- 発行部数・売上・ユーザー数は、出典により数字が大きく異なる

学術的引用、商業企画の根拠、報道等に用いる場合は、**必ず一次情報で裏を取っていただきたい**。

### 逆に、信頼していただける部分

一方で、本レポートの中心は数値ではなく**構造の記述**にある。

- 第3章（ジャンルの六成分モデル）
- 第4章（物語構造・快楽エンジン・ざまぁの五段階）
- 第5章（主人公類型）
- 第6章（キャラクターの六機能）
- 第7章（世界設定の共有インフラ）
- 第8章（文体・タイトルの工学）
- 第11章（実践ガイド）と付録C・D

これらは多数の作品に共通するパターンの抽象化であり、**個別の年代誤差では揺らがない**。本レポートの価値の重心はここにある。

## E-2　参照した情報源の種類

具体的なURL単位での網羅的な列挙は、上記の制約により行えないが、参照した情報の種類を明示しておく。

**（1）検索エンジン経由で得られた要約情報**

- 「小説家になろう」の沿革、ランキング制度、ジャンル区分に関する解説記事
- なろう作品のトレンド変遷を扱った個人の分析記事・まとめ記事
- 投稿サイト間の比較を行ったエッセイ・分析
- 個別作品（『乙女ゲームの破滅フラグしかない悪役令嬢に転生してしまった…』等）の連載期間・書籍化に関する情報

**（2）学術・準学術的な研究**

- 小説投稿サイトのジャンル・キーワードの頻出語彙に着目した比較分析（メタデータ関連の学術誌に掲載された研究など）
- ライトノベル・WEB小説をめぐるメディア論・出版産業論の議論

**（3）一般に共有されている知識**

- 主要作品の内容・構造に関する、広く流通した理解
- 「なろう系」をめぐる批評・論争の言説

## E-3　さらに調べたい読者のための指針

本レポートの内容を検証・拡張したい場合、次の順序で当たることを推奨する。

### 一次情報

1. **各投稿サイトのランキングページ**（年間・累計ランキング）を直接見る。とくに「累計ランキング」は歴史的な集積を示す
2. **各サイトのヘルプ・ガイドライン**。ポイントの計算方式、ジャンル区分の公式な定義はここにある
3. **作品本文**。最終的にはこれに勝る資料はない。とくに序盤10話の構成は、本レポート第4章・第11章の主張を検証するのに適している
4. **各出版社のレーベル公式サイト**。刊行ラインナップからレーベルの傾向が読める

### 二次情報

5. **作者自身による分析エッセイ**。投稿サイト上に、書き手による市場分析・執筆論が多数投稿されている。当事者の実感として貴重
6. **書籍化作家のインタビュー・後書き**
7. **出版業界の統計**（出版科学研究所の年鑑など）。コミック市場とライトノベル市場の推移を確認できる

### 学術研究

8. **ライトノベル研究・メディア論の論文**。CiNii等で「ウェブ小説」「小説投稿サイト」「なろう」を検索
9. **ゲーム的リアリズム論**（東浩紀ほか）を含む、キャラクター小説をめぐる理論的議論
10. **プラットフォーム研究**の一般理論（アルゴリズムが表現を規定する構造の分析）

### 比較対象

11. **韓国・中国のWEB小説市場**に関する報告。産業構造の比較は、日本モデルの特異性を浮かび上がらせる

## E-4　この分野を調べるときの注意点

**（1）「読んでいない批判」に注意する。**
WEB小説はタイトルだけで揶揄できるため、実際に読んでいない論者による批判が大量に流通している。分析の材料にするなら、必ず本文にあたること。

**（2）「昔は良かった」論に注意する。**
どの時期にも「最近のなろうはつまらない」という言説が存在する。これはほぼ常に、論者自身の読書歴と嗜好の変化を反映している。

**（3）ランキングは「人気」の一側面にすぎない。**
第9章で述べたとおり、累計・日間・書籍部数・コミック部数は、それぞれ別のものを測っている。単一の指標で「歴代最高」を語ることはできない。

**（4）女性向け市場を軽視しない。**
男性向け作品を中心に語られることが多いが、市場規模・回転速度・多様性のいずれにおいても、女性向け市場は無視できない。むしろ関係性の設計技術では先行している。

**（5）変化が速い。**
半年前の分析が古びる分野である。本レポートも2026年8月時点の整理であり、継続的な更新を要する。

## E-5　謝辞に代えて

本レポートが記述した「テンプレ」「文法」「型」は、特定の誰かが発明したものではない。

二十年にわたって、数十万人の書き手が、無償で、余暇に、時に生活を削って書き続けた膨大な試行の集積である。そのほとんどは読まれず、ランキングに載らず、書籍にもならなかった。

だが、それらすべてが、この形式を作った。

本レポートは、その集合的な作業の結果を、後から整理して記述したにすぎない。もし本レポートに何らかの価値があるとすれば、それは分析者の功績ではなく、**書き続けた人々の功績**である。
