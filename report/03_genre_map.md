# 第3章　ジャンル地図 ―― 分類・成分・組み合わせ

> **本章の要点**
> WEB小説のジャンルは、公式の分類体系（サイトのジャンル区分）と、実効的な分類体系（タグ・テンプレ名）の二重構造をなす。創作にとって有用なのは後者だが、後者は数が多く流動的である。そこで本章では、ジャンルを**六つの成分軸に分解**し、既存ジャンルをその組み合わせとして記述する方法を提示する。この「成分表」があれば、既存ジャンルの理解も、新ジャンルの設計も、同じ道具で扱える。

---

## 3-1　二重の分類体系

### 公式ジャンル ―― 競争区画としての分類

第1章で見たとおり、投稿サイトのジャンル区分は「作品の内容を表すラベル」であると同時に「**どのランキングで戦うか**」の選択である。なろうの区分（大ジャンル：恋愛／ファンタジー／文芸／SF／その他）は粗く、実際の作品の差異をほとんど表現できない。「ハイファンタジー」という一区画のなかに、重厚な叙事詩も、スローライフも、ざまぁ短編も同居している。

したがって公式ジャンルは、**分析の道具としてはほぼ無力**である。しかし戦略の道具としては重要で、次の三点を押さえておけばよい。

1. 大区画ほど競争が激しい（ハイファンタジー＝最激戦区）
2. 誤ったジャンルに置くと、期待の異なる読者に評価される（＝低評価）
3. 区画の新設・再編は、そのたびに空白地帯を生む

### 実効ジャンル ―― タグとテンプレ名による分類

読者と書き手が実際に使っているのは、**タグとテンプレ名による分類**である。「異世界転生」「追放」「ざまぁ」「悪役令嬢」「スローライフ」「主人公最強」「чит」「もふもふ」「内政」「テイマー」――これらは公式区分ではないが、事実上のジャンル名として機能している。

実効ジャンルの特徴は次の通り。

- **多重所属が前提**：一作品が10個以上のタグを持つのが普通
- **快楽の予告として機能する**：「ざまぁ」は内容ではなく**読後感**を約束する
- **生成と消滅が速い**：数年で新語が生まれ、数年で古びる
- **語がジャンルを作る**：名前がついた瞬間に、それを目指す作品が現れる

> **重要な観察**：WEB小説のジャンル名の多くは、**主人公の状況**（追放された、転生した、婚約破棄された）か、**読者が得る感情**（ざまぁ、ほのぼの、溺愛）を指している。舞台や題材ではない。これは、この形式が**題材ではなく体験を売っている**ことの端的な現れである。

## 3-2　六成分モデル ―― ジャンルを分解する

実効ジャンルを整理するために、以下の六つの軸を導入する。ほとんどのWEB小説は、この六軸の値の組み合わせとして記述できる。

### 軸1｜世界（WHERE）――物語の舞台

| 値 | 説明 | 例 |
|---|---|---|
| 異世界（中世欧州風） | 最も標準的。剣と魔法、王国と冒険者ギルド | 大半のハイファンタジー |
| 異世界（ゲーム世界） | 乙女ゲーム、RPG、VRMMOの内部 | 悪役令嬢もの、VRMMOもの |
| 現代（そのまま） | 現代日本に超常が入り込む | 現代ダンジョン、能力バトル |
| 現代（異世界と接続） | ゲート、召喚、行き来ができる | 『ゲート』型、二拠点もの |
| 疑似歴史（中華・和風・北欧） | 後宮、戦国、ヴァイキング等 | 中華後宮もの、和風あやかし |
| 近未来・SF | 宇宙、AI、ポストアポカリプス | SF区分の作品群 |

### 軸2｜到達経路（HOW ARRIVED）――主人公はどうやってその立場に来たか

| 値 | 説明 | 効果 |
|---|---|---|
| 転生（乳児から） | 死んで赤ん坊として生まれ直す | 人生をやり直す物語が書ける。成長過程を描ける |
| 転生（成人体で） | 死んで別人の体・年齢で目覚める | 導入が速い。前世の記憶＝チート |
| 転移 | 生きたまま身体ごと移動 | 帰還という目的を設定できる。現代の知識・道具を持ち込める |
| 憑依 | 既存の人物の中に入る | 既にある人間関係・立場を引き継げる（悪役令嬢の標準形） |
| ループ | 時間が巻き戻る | 知識アドバンテージと絶望を同時に供給できる |
| 覚醒（土着） | 転生ではなく、その世界の住人が力に目覚める | 「元日本人」の説明を省ける。異世界内在の物語 |
| 現地人（記憶なし） | 完全な現地人が主人公 | 世界への没入が深い。ただし共感の足場が要る |

### 軸3｜能力獲得（POWER SOURCE）――何によって特別なのか

| 値 | 説明 |
|---|---|
| 女神・神からの付与 | 最も手軽。「チートスキル」の標準的な出所 |
| システム（世界の仕組み） | ステータス、スキルツリー、レベル。ゲーム的リアリズムの中核 |
| 前世の知識・技術 | 内政チート、技術チート、料理、医療 |
| 原作知識 | ゲーム・小説の展開を知っている（悪役令嬢、乙女ゲー転生） |
| 血統・種族 | 貴族、魔族、竜、精霊。生まれつきの格 |
| 努力・修行 | 相対的に希少。長期連載型の成長物語 |
| 外れスキル（再解釈） | 無用と思われた能力が実は最強。**追放ものの標準装備** |
| 呪い・代償 | 力に対価がある。ダーク寄りの作品 |

### 軸4｜目的（WHAT FOR）――何を目指すか

| 値 | 典型的な展開 |
|---|---|
| 生存 | サバイバル、成長、脱出 |
| 承認・成り上がり | 冒険者ランク、地位、名声 |
| 復讐・見返し | ざまぁ、断罪、返り討ち |
| 安寧・スローライフ | 農業、料理、店舗経営、辺境開拓 |
| 建設・統治 | 内政、国づくり、領地経営 |
| 探究 | 魔法研究、ダンジョン攻略、真相究明 |
| 恋愛・関係 | 溺愛、婚約、家族形成 |
| 回避 | 破滅回避、死亡フラグ回避 |
| 帰還 | 元の世界へ戻る |

### 軸5｜快楽エンジン（WHAT FEELS GOOD）――読者の報酬は何か

これが**もっとも実務的に重要な軸**である。第4章で詳述するが、主要なものを挙げる。

| エンジン | 供給される感情 |
|---|---|
| 無双（俺TUEEE） | 有能感、万能感 |
| ざまぁ | 報復的正義、溜飲を下げる快感 |
| 勘違い | 優越的な観察、笑い |
| 承認・称賛 | 自己価値の確認 |
| 収集・成長 | 蓄積の実感（レベル、スキル、仲間、拠点） |
| 溺愛・受容 | 無条件に愛される安心 |
| 癒し・ほのぼの | 脅かされない安全 |
| 謎解き・仕掛け | 知的満足 |
| 感動・喪失 | カタルシス（相対的に少数派） |

### 軸6｜トーン（HOW IT FEELS）――語りの温度

シリアス／コメディ／ほのぼの／ダーク／鬱／メタ・パロディ／叙事詩的

## 3-3　成分表による記述の実例

六軸を使うと、既存の代表的な作品・ジャンルを次のように記述できる。

**標準的な異世界転生チートもの**
> 世界＝異世界中世／経路＝転生（成人体）／能力＝女神付与＋システム／目的＝承認・成り上がり／エンジン＝無双＋称賛／トーン＝軽いシリアス

**追放もの**
> 世界＝異世界中世／経路＝現地人／能力＝外れスキルの再解釈／目的＝復讐＋安寧／エンジン＝ざまぁ＋承認／トーン＝シリアス〜軽快

**悪役令嬢もの（破滅回避型）**
> 世界＝異世界（ゲーム世界）／経路＝憑依／能力＝原作知識／目的＝回避／エンジン＝勘違い＋溺愛／トーン＝コメディ

**スローライフもの**
> 世界＝異世界中世（辺境）／経路＝転移／能力＝前世の知識／目的＝安寧／エンジン＝癒し＋収集／トーン＝ほのぼの

**現代ダンジョンもの**
> 世界＝現代／経路＝覚醒／能力＝システム／目的＝成り上がり／エンジン＝無双＋承認（可視化された評価）／トーン＝シリアス

**『無職転生』型**
> 世界＝異世界中世／経路＝転生（乳児）／能力＝前世の後悔＋才能／目的＝生存と人生の再構築／エンジン＝成長＋喪失のカタルシス／トーン＝叙事詩的

> **創作への応用**：新ジャンルを設計したければ、六軸の**まだ埋まっていない組み合わせ**を探せばよい。たとえば「経路＝ループ × 目的＝スローライフ × トーン＝ほのぼの」は比較的手薄な領域である。ただし、空白には空白である理由（読者の欲求と噛み合わない）がある場合も多いので、**なぜ空白なのかを考えることが同じくらい重要**である。

## 3-4　男性向け主要ジャンル詳解

以下、実効ジャンルとして確立しているものを、**構造・快楽・注意点**の三点で記述する。

### ① 異世界転生チート（基本形）

- **構造**：死 → 女神 → 能力付与 → 転生 → 力の確認 → 街 → 冒険者登録 → 実力の露見 → 称賛の連鎖
- **快楽**：無双＋称賛。読者は主人公と一体化して「正しく評価される」体験をする
- **注意点**：最も飽和した領域。**差別化は「能力の種類」ではなく「能力の使い方」でしか生まれない**。「収納が実は無限の亜空間だった」より「収納を使って何をするか」に個性が宿る

### ② 追放・クビ・パーティ離脱もの

- **構造**：不当な追放 → 実は主人公が要だった → 双方の運命が分岐 → 追放側の凋落 → 主人公の栄達 → 再会と断罪
- **快楽**：ざまぁ。**冒頭で怒りを起動し、中盤で解消する**という設計
- **注意点**：追放側の描写が薄いと「悪意の人形」になり、ざまぁのカタルシスが弱くなる。**追放が「一応の合理性を持つ」ほど、反転は効く**

### ③ ざまぁ（独立ジャンルとして）

- **構造**：加害 → 忍従 → 反転 → 制裁 → 拒絶
- **快楽**：報復的正義。とくに「加害者が自分の非を悟る瞬間」が最大の山
- **注意点**：**主人公が能動的に復讐すると読者の共感が下がる**。多くの成功作では、主人公はただ正しく生き、加害者が勝手に自滅する。「主人公の手を汚さない」ことが暗黙のルール

### ④ 主人公最強・無双

- **構造**：強さを段階的に露出させ、そのたびに周囲の評価が更新される
- **快楽**：格の提示
- **注意点**：インフレ管理が最大の課題（→第5章5-6）。「強さの上限」ではなく「**強さが解決できない問題**」を用意することで物語が続く

### ⑤ 勘違い系

- **構造**：主人公の認識と周囲の認識が食い違い、そのズレが好転を生む
- **快楽**：優越的な観察（読者だけが両方の視点を知っている）
- **注意点**：**視点の切り替えが技術的な要**。周囲視点のパートがないと勘違いが成立しない。ズレが解消されると物語が終わるので、解消を遅らせる工夫が必要

### ⑥ 内政・領地経営・国づくり

- **構造**：荒廃した土地／小国を与えられる → 前世の知識で改善 → 人口・経済の成長 → 外部からの干渉 → 防衛・拡大
- **快楽**：蓄積と設計の快感（シミュレーションゲーム的満足）
- **注意点**：**数字の見せ方が生命線**。人口、収穫量、税収を可視化すると成長が実感される。逆に、経済的な因果が雑だと知識層の読者に見放される

### ⑦ 生産・職人・スキル特化

- **構造**：非戦闘的な職能（鍛冶、錬金、薬師、料理、建築、農業）で価値を証明する
- **快楽**：職人的満足、ものづくりの過程
- **注意点**：**過程の描写が面白さの本体**。結果だけ書くと機能しない。作者の実地の知識が最も効くジャンル

### ⑧ ダンジョン攻略・探索

- **構造**：階層構造の踏破。明快な目標と段階的な達成
- **快楽**：攻略の進捗、未知の踏破
- **注意点**：階層ごとに新要素を出さないと単調になる。**「深いほど良い」以外の価値軸**（安全確保、資源、人間関係）を並走させたい

### ⑨ テイマー・従魔・もふもふ

- **構造**：仲間となる生物を得て、育て、増やす
- **快楽**：収集＋愛着＋無条件の信頼
- **注意点**：従魔の個性づけが命。**言葉を話すか話さないかで作品の性格が変わる**

### ⑩ スローライフ・辺境開拓

- **構造**：競争からの離脱 → 小さな土地 → 生活の充実 → 訪れる人々との関係 → 小さな事件
- **快楽**：安全と充足。「何も脅かされない」ことそのもの
- **注意点**：**葛藤が薄い分、退屈と紙一重**。定期的に小さな外部干渉（客、依頼、トラブル）を入れて波を作る

### ⑪ VRMMO・ゲーム内

- **構造**：ゲームというルール系の中での最適化・攻略
- **快楽**：ルールの読み解きと逆用（システムの穴を突く快感）
- **注意点**：**現実側の描写をどれだけ入れるか**が設計上の分岐点。全部ゲーム内にすると異世界ものと変わらなくなる

### ⑫ 現代ダンジョン・現代能力もの

- **構造**：日常世界に超常が制度化されている → 主人公が力に目覚める → ランク・組織・報道の中で成り上がる
- **快楽**：可視化された承認（ランク、報道、配信、SNS）
- **注意点**：現代を舞台にする以上、**社会制度の整合性**を問われる。法律、税、保険、報道――これらを設計するほど説得力が増す

### ⑬ 学園・隠された実力

- **構造**：能力を隠して入学 → 侮られる → 事件 → 実力の露見 → 評価の反転
- **快楽**：正体露見の瞬間の快感
- **注意点**：露見をどこで使うかが全て。**小出しにして、毎回別の相手に対して行う**のが定石

### ⑭ 人外・モンスター転生

- **構造**：スライム、蜘蛛、剣、スケルトンなどに転生 → 生存 → 進化 → 人型化／勢力形成
- **快楽**：底辺からの成長曲線、進化の達成感
- **注意点**：**言語・社会性の欠如をどう補うか**が技術的な難所。独白の質が作品の質になる

### ⑮ 復讐・ダーク

- **構造**：喪失 → 力の獲得 → 冷徹な報復
- **快楽**：抑圧された攻撃性の解放
- **注意点**：主流ではない。**読者のストレス耐性を見極める必要**があり、ランキング上位は狙いにくいが、固定読者は濃い

## 3-5　女性向け主要ジャンル詳解

女性向け（なろうの「異世界〔恋愛〕」「現実世界〔恋愛〕」、およびアルファポリス・ムーンライト等）は、男性向けよりも**回転が速く、細分化が進んでいる**。

### ① 悪役令嬢（破滅回避型）

- **構造**：乙女ゲームの悪役令嬢に転生 → 断罪エンドを知っている → 回避行動 → 空回り → なぜか好感度上昇 → 破滅の回避と幸福
- **快楽**：勘違い＋溺愛＋知識アドバンテージ
- **注意点**：**「知っているのに変えられない」緊張が薄れると、ただの好かれる話になる**。原作補正・強制力という装置を入れる作品が多い

### ② 婚約破棄・断罪ざまぁ

- **構造**：公衆の面前で冤罪による婚約破棄 → 実は令嬢が全てを支えていた → 相手方の凋落 → 令嬢の真価が明らかに → 謝罪と拒絶
- **快楽**：ざまぁ、正当な評価の回復
- **注意点**：**短編・中編で完成度が高い**形式。冒頭のシーンをそのまま第1話に置ける強さがある

### ③ 追放令嬢・虐げられ系

- **構造**：家族・婚約者から冷遇 → 追放または出奔 → 外部で価値を認められる → 溺愛される
- **快楽**：救済と受容
- **注意点**：**忍従期間の長さが読者の耐性を試す**。近年は忍従を極端に短縮し、早期に救済者を登場させる傾向

### ④ 聖女・治癒・職能もの

- **構造**：特別な力を持つが正当に扱われない → 別の場所で評価される
- **快楽**：能力による承認、感謝される快感
- **注意点**：「偽聖女」との対比構造が定番。**戦闘ではなく「助ける」ことで無双する**という女性向け特有の力の形

### ⑤ 溺愛・執着系

- **構造**：ヒロインが理由もわからないまま、極端に強い愛情を注がれる
- **快楽**：無条件の受容、自己肯定
- **注意点**：**相手の執着の理由**を後半で明かす構成が定石（前世、幼少期の出会い、一目惚れの必然）

### ⑥ 契約結婚・政略結婚

- **構造**：愛のない結婚から始まり、徐々に信頼と愛情が育つ
- **快楽**：関係の変化そのもの
- **注意点**：**契約という枠が二人の距離を管理する装置**として機能する。枠がなくなる瞬間が最大の山

### ⑦ モブ転生・脇役転生

- **構造**：物語の主要人物ではない立場に転生 → 外側から観測 → 意図せず物語を変えてしまう
- **快楽**：メタ的な優越、巻き込まれの面白さ
- **注意点**：**主人公に「目立ちたくない」という明確な欲求**を与えると駆動しやすい

### ⑧ 中華後宮・和風

- **構造**：宮廷という閉鎖社会での権力闘争、謎解き、身分の上昇
- **快楽**：知略、身分差、様式美
- **注意点**：**風俗の考証が読者評価を左右する**。衣服、食事、儀礼の具体が効く

### ⑨ ループ・やり直し（女性向け）

- **構造**：処刑・死別の後に時間が巻き戻る → 知識を使って運命を変える
- **快楽**：知識アドバンテージ＋喪失の回復
- **注意点**：**何を変え、何を変えられないか**のルール設計が肝

### ⑩ 悪役令嬢・最強／自立型

- **構造**：令嬢が武力・魔力・商才で自立し、恋愛は従属的
- **快楽**：自己実現、痛快さ
- **注意点**：2020年代に伸びた領域。**恋愛を「報酬」ではなく「選択肢の一つ」に置く**設計

### ⑪ 家族・育児・もふもふ癒し

- **構造**：子ども、幼獣、義理の家族との生活
- **快楽**：無償の愛着、保護する側の充足
- **注意点**：近年もっとも安定して支持される領域の一つ

### ⑫ 現代恋愛・オフィス・純愛

- **構造**：現実世界での関係の進展
- **快楽**：共感、リアリティ
- **注意点**：なろうでは相対的に不利。**エブリスタ・アルファポリス・カクヨム向き**

## 3-6　ジャンルの組み合わせと「空白地帯」

現代のWEB小説では、**単一ジャンルの純粋な作品はむしろ少数**である。ほとんどが二つ以上のジャンルの掛け合わせで成立している。

**成功している組み合わせの例**

| 組み合わせ | 効果 |
|---|---|
| 追放 × スローライフ | 怒りで始まり、癒しで持続する（導入と継続の分業） |
| 悪役令嬢 × 最強 | 女性向けの様式に男性向けの快楽を接続 |
| 内政 × 戦記 | 建設と防衛の交互リズム |
| ダンジョン × 経営 | 探索の成果を蓄積に変換できる |
| 現代ダンジョン × 配信 | 承認の可視化を構造の中心に |
| テイマー × 生産 | 収集と創造の二重の蓄積 |
| ループ × ミステリ | 知識アドバンテージを謎解きに変換 |

**組み合わせの設計原理**

有効な組み合わせには法則がある。**「読者を引き込む要素」と「読者を留める要素」を分業させる**ことである。

- ざまぁ、追放、婚約破棄、無双は**引き込みに強く、持続に弱い**（怒りや驚きは長続きしない）
- スローライフ、内政、生産、テイマー、育児は**持続に強く、引き込みに弱い**（穏やかな快楽は初速が出ない）

したがって「**前者で始めて後者で続ける**」という設計が、構造的に最も安定する。実際、ランキング上位の長期連載の多くはこの形をとっている。

**比較的手薄な領域（2026年時点の観察）**

- 老年・中年主人公の非戦闘的な物語（一定数あるが飽和していない）
- 都市計画・インフラ・公衆衛生を主題化した内政もの
- 非ヨーロッパ・非中華の文化圏を舞台にした異世界
- 「力を失っていく」方向の物語（インフレの逆）
- 集団・組織を主人公とする物語（個人英雄譚以外）
- 労働と職能の現実的な描写（現代ものとして）

ただし前述の通り、空白には理由がある場合がある。**手薄な領域に挑むなら、「読者の既知の快楽をどこで供給するか」を必ず併設すること**。まったく新しい快楽だけで勝負するのは、WEB小説の環境ではきわめて難しい。

## 3-7　本章のまとめ ―― ジャンル選択の実務

1. **公式ジャンルは戦場の選択**である。作品の性質だけでなく、競争密度を見て決める。
2. **実効ジャンル（タグ）は読者との契約**である。約束したものは必ず供給する。
3. **六成分モデル**（世界／経路／能力／目的／エンジン／トーン）で自作を記述してみる。どこかの軸が「その他大勢と同じ」なら、そこが差別化の候補地である。
4. **一点だけずらす**のが実務的な最適解。六軸すべてを新奇にすると、読者は足場を失う。**五つは既知、一つだけ新規**が、もっとも受け入れられやすい配合である。
5. **引き込み要素と持続要素を分業**させる。
