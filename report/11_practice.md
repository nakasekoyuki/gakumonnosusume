# 第11章　創作実践ガイド ―― 何をどう使うか

> **本章の要点**
> ここまでの分析を、実際に手を動かすための手順に変換する。企画の立て方、冒頭10話の設計、キャラクターと世界設定の最小構成、更新運用、推敲、そして「続けるための技術」まで。すべて、明日から使える形で記述する。

---

## 11-1　企画 ―― 最初に決める四つのこと

長編を書き始める前に、次の四つを紙に書き出す。これだけで、失速の大半は防げる。

### ① コンセプト（一行）

**形式**：`[誰が][どういう状況で][何をする]話`

例：

- 「追放された鑑定士が、辺境で万物の価値を見抜いて商会を立ち上げる話」
- 「破滅を知る悪役令嬢が、婚約破棄を回避しようとして逆に全員に好かれる話」
- 「現代日本のダンジョンで、清掃業者として底辺から最強になる話」

**チェック**：

- 一行で言えないなら、まだ企画がまとまっていない
- 「異世界に転生してチートで無双する」だけでは、まだ企画ではない（それは形式であって内容ではない）
- **その一行が面白そうに聞こえるか**を、自分に問う

### ② 快楽エンジン（何が繰り返し起きて、読者が何を感じるか）

第4章の分類から選ぶ：無双／ざまぁ／勘違い／承認／収集／溺愛／癒し／謎解き。

**形式**：`毎回[誰]が[主人公の何]に[どう反応]し、読者は[何]を感じる`

例：「毎回、主人公を侮った相手が鑑定結果の正確さに驚愕し、読者は溜飲を下げる」

**チェック**：

- このエンジンは、何話分の燃料があるか（→第4章4-4）
- 燃料が尽きたら何に乗り換えるか、第二のエンジンを決めてあるか

### ③ 差別化の一点

第3章の六成分（世界／経路／能力／目的／エンジン／トーン）のうち、**一つだけを他と違うものにする**。残り五つは既存の標準に合わせる。

例：

- 世界を変える：「異世界ではなく、現代の廃鉱山にダンジョンがある」
- 能力を変える：「戦闘能力ではなく、あらゆる契約書の不備を見抜く力」
- 目的を変える：「成り上がりではなく、失われた図書館を再建すること」
- トーンを変える：「シリアスではなく、全編が業務日誌の形式」

**チェック**：その一点が、**タイトルとあらすじに書けるか**。書けないなら、読者には伝わらない。

### ④ 終わり方

内容ではなく、**到達すべき状態**を一行で決める。

例：「主人公が、失われた図書館を再建し、そこに人々が集まっている状態」

**チェック**：これが決まっていれば、途中で迷子にならない。決まっていない連載は、高い確率でエタる。

## 11-2　企画の自己診断シート

書き始める前に、次の10問に答える。7つ以上「はい」でなければ、企画を練り直す。

1. コンセプトを一行で言えるか
2. その一行を聞いた人が「続きが気になる」と思うか
3. 読者が繰り返し得る快楽を、一語で言えるか
4. その快楽は、10話目でも、50話目でも供給できるか
5. 他の作品と違う点を、一つ明確に言えるか
6. その違いを、タイトルとあらすじに書けるか
7. 主人公に、能力では解決できない欠落があるか
8. 第1話で何が起きるか、決まっているか
9. 最終的にどうなれば終わりか、決まっているか
10. 自分がこの話を、100話書きたいと思えるか

**10番目がもっとも重要である。** 市場に合わせただけの企画は、書いている本人が飽きる。飽きた作品は、必ず読者にも伝わる。

## 11-3　冒頭10話の設計テンプレート

もっとも重要な区間である。標準的な設計例を示す（追放もの／異世界転生ものを想定。他ジャンルでも構造は転用できる）。

| 話 | 内容 | 目的 |
|---|---|---|
| **1話** | **タイトルの約束が実行される**。追放される／転生する／婚約破棄される。末尾に強い引き | 離脱防止。契約の履行 |
| **2話** | 主人公の状況整理。能力の存在が示唆される。小さな成功をひとつ | 「この先も面白そう」の予感 |
| **3話** | **快楽エンジンの初回作動**。誰かが主人公を正しく評価する、または主人公が力を示す | 継続判断の関門を突破 |
| **4話** | 世界の拡張。街／組織／制度に触れる。観測者の登場 | 舞台の提示 |
| **5話** | 最初の仲間または継続的な関係の獲得 | 孤独からの脱出。鏡役の確保 |
| **6話** | 小さな障害と、その解決。能力の別の使い方を発見 | 能力の奥行きを示す |
| **7話** | **他者視点の挿話**。外から見た主人公の異常さ | 承認の供給。エンジンの燃料補給 |
| **8話** | 中期目標の提示。「これから何を目指すのか」 | 10話の壁への準備 |
| **9話** | 目標に向けた最初の行動。障害の予告 | 物語の駆動 |
| **10話** | **第一の山場**。ここまでの積み重ねが結実する。次のアークの予告 | 区切りと継続 |

### 各話の内部構造（再掲）

```
[冒頭 100〜300字]  前話からの接続
[展開 1,000〜2,000字]  この話の出来事
[山　 500〜1,000字]  快の供給点
[引き 100〜300字]  次話への未解決
```

### 冒頭でやってはいけないこと

- 世界設定の説明から始める
- 主人公の平穏な日常を3話以上続ける
- 主人公が異世界に行くまでに3話以上かける
- タイトルで約束したものが5話まで出てこない
- 主人公が何も達成しないまま10話が過ぎる

## 11-4　プロットの作り方（WEB連載向け）

### 三段階で作る

**段階1：アークの列挙（大枠）**

物語全体を、10〜40話程度の「章」に区切って並べる。各章について、

- 舞台（どこで）
- 課題（何を解決するか）
- 獲得（章の終わりに主人公が得るもの：仲間、地位、能力、情報）
- 山場（もっとも盛り上がる場面）

これを5〜8章分書く。それ以上先は、書きながら決めてよい。

**段階2：話単位への分解（中枠）**

直近の1章分を、話ごとに一行で書き出す。

```
第11話　王都に到着。門番に絡まれる
第12話　宿を探す。冒険者ギルドの噂を聞く
第13話　ギルドで登録。鑑定を受けて騒ぎになる
...
```

**段階3：執筆（細部）**

書きながら、細部は変わってよい。**プロットは地図であって線路ではない**。

### 「先に決めておくべきこと」と「決めなくてよいこと」

| 先に決める | 決めなくてよい |
|---|---|
| 主人公の欠落と目的 | 各話の細かい会話 |
| 快楽エンジン | 脇役の名前（登場時に決めてよい） |
| 能力のルールと制約 | 戦闘の細部 |
| 終わり方（到達状態） | 途中の寄り道エピソード |
| 主要人物3〜5人の役割 | 世界の全地理 |
| 貨幣と物価 | 全種族の詳細設定 |

## 11-5　キャラクター作成の手順

### 主人公（30分でできる）

1. **前世の属性を決める**（→第5章5-2）。動機と技能の両方を正当化するものを選ぶ
2. **能力を決める**。まず「面白い使い方」を3つ考え、そこから能力名を逆算する
3. **制約を決める**。何ができないか
4. **性格類型を二つ選ぶ**（→第5章5-4）
5. **欠落をひとつ与える**。能力では埋まらないもの
6. **一人称と口調を決める**。「俺／私／僕」と語尾

### 脇役（1人5分）

1. **機能を決める**（観測者／供給者／受益者／鏡／障害／報酬のどれか）
2. **主人公との距離を決める**（味方／中立／敵、近い／遠い）
3. **一目でわかる特徴を一つ**（外見、口癖、癖）
4. **主人公にできないことを一つ**担わせる

**注意**：脇役に凝りすぎない。**登場した時点で決めれば十分**である。事前に20人分の設定を作っても、多くは使われない。

### 最小構成のキャスト

長編の開始時点で必要なのは、次の5人である。

| 役 | 機能 |
|---|---|
| 主人公 | ― |
| 相棒／最初の仲間 | 鏡（内面を引き出す） |
| 権威ある観測者 | 主人公の価値を判定できる立場（ギルドマスター、師匠、貴族） |
| 加害者／障害 | 冒頭の不当さ、または継続的な脅威 |
| 供給者 | 依頼・情報・資源を持ってくる |

この5人が揃っていれば、物語は動く。増やすのは後でよい。

## 11-6　世界設定の最小構成（2時間でできる）

第7章の内容を、実作の初期段階に必要な分だけ圧縮する。

**必須（これだけあれば書き始められる）**

1. **文明水準**：一行で。「中世ヨーロッパ風、ただし魔道具により照明と保存は現代並み」
2. **主人公のいる街**：規模、産業、特徴、主要施設3つ
3. **貨幣と物価**：A4半分の表（→第7章7-4）
4. **魔法の「できないこと」**：3つ（例：死者は蘇らない、遠隔転移はできない、他人の心は読めない）
5. **危険の所在**：主人公を脅かすもの（魔物／盗賊／貴族／飢餓）
6. **主人公の能力が、この世界でなぜ珍しいのか**：一行

**書きながら足す**

- 国家（登場したとき）
- 種族（登場したとき）
- 宗教（必要になったとき）
- 歴史（伏線が必要になったとき）

**設定資料の管理**

長期連載では、設定の矛盾が最大の敵になる。実務的には、

- 一つのファイルに、**登場人物一覧**（名前・所属・特徴・初出話数）
- **固有名詞一覧**（地名、組織名、アイテム名、表記ゆれ防止）
- **時系列表**（何話目に何が起きたか、季節、経過日数）
- **能力の使用履歴**（できると書いたこと、できないと書いたこと）

これを更新し続けることが、100話を超える連載の生命線である。

## 11-7　執筆と更新の運用

### 開始前

- **20〜30話分をストックする**。最低でも10話
- 全話を通して読み返し、序盤の失速を修正する
- タイトル、あらすじ、タグを確定する
- 連絡先を設定に記載する

### 開始後

| 期間 | 更新頻度 | 目的 |
|---|---|---|
| 1〜2週目 | 毎日、または1日2回 | 日間ランキングへの露出 |
| 3〜8週目 | 毎日 | 習慣化と累積 |
| 以降 | 週3〜5回、または定曜日 | 持続可能なペース |

**重要**：最初に無理をして、3週間で倒れるより、**続けられるペースを守るほうが最終的な到達点は高い**。

### 執筆速度の現実

- 1話3,000字を書くのに、慣れた書き手で1〜3時間
- 毎日更新は、実質的に**毎日2〜3時間の作業**を意味する
- 兼業でこれを1年続けるのは、相当な負荷である

したがって、**最初からペースを設計する**こと。「毎日更新しないと勝てない」は事実だが、「毎日更新できないなら書くな」ではない。週2回で200話に到達した作品は、毎日更新で30話で止まった作品よりはるかに強い。

## 11-8　推敲の実務

WEB連載では、公開後の大改稿が難しい。したがって**公開前の推敲がすべて**である。

### 三段階の推敲

**第1段階：構造（書いた直後にはやらない。一日置く）**

- この話に、快の供給点があるか
- 引きは機能しているか
- 前話とのつながりは自然か
- この話は必要か（削れないか）

**第2段階：文章**

- 同じ語尾が3回続いていないか
- 一段落に同じ単語が3回出ていないか
- 「思った」「感じた」で処理した感情はないか
- 修飾が長すぎる文はないか
- 読者が「何も見えていない」箇所はないか

**第3段階：表記**

- 誤字脱字
- 固有名詞の表記ゆれ
- 数字・単位の統一
- 設定の矛盾（資料と照合）

### 効率的な方法

- **音読する**。詰まる場所が問題箇所である
- **スマホの画面で確認する**。PCで書いてPCで読むと、実際の見え方がわからない
- **時間を置く**。書いた直後は誤りが見えない
- **機械的チェックを併用する**（誤字検出ツール、AI校正）

## 11-9　ランキング戦略の現実

### できること

- 開始時期を選ぶ（大型作品の連載開始と重ならない時期）
- ストックによる連続更新で初速を作る
- タイトルとあらすじを最適化する
- 適切なジャンルを選ぶ（競争密度を考慮する）
- タグを正確に設定する
- 短編でヒットを作り、長編に誘導する
- 複数サイトに展開する
- 完結させて、累計ランキングでの持続力を得る

### できないこと・してはいけないこと

- 複数アカウントによるポイント操作（規約違反）
- 相互評価の組織化（発覚時のリスクが大きい）
- 他作品への攻撃
- 内容と無関係なタグの大量付与

### 冷徹な事実

> ランキング上位に入る作品は、投稿作品全体の**0.1%未満**である。
> つまり、正しく書いても、大半の作品は上位に入らない。
>
> これは書き手の価値の否定ではない。**発見装置の構造的な帰結**である（→第9章9-2）。
>
> したがって、目標設定は次のように立てるべきである。
> - ランキング上位（制御できない）を目標にしない
> - **完結させること**（制御できる）を目標にする
> - **前作より良いものを書くこと**（制御できる）を目標にする
> - 読者が10人つくこと、100人つくことを、段階的な達成として認める

## 11-10　続けるための技術

長編WEB小説の最大の敵は、才能不足でも競争でもなく、**執筆の中断**である。

### エタりの主要因と対策

| 要因 | 対策 |
|---|---|
| 反応がない | 開始前に「反応がなくても30話は書く」と決める。数字を毎日見ない |
| 否定的な感想 | 感想を見る日を週1に決める。通知を切る |
| 話の行き先を見失う | 終わり方（到達状態）を最初に決めておく |
| 設定が破綻した | 設定資料を作る。矛盾は「後付けで説明」より「そういうものだった」で押し切るほうが被害が小さいことも多い |
| 生活の変化 | ストックを常に5話分持つ。更新頻度を下げる宣言をする（無断の失踪より、宣言のほうが読者は待つ） |
| 飽きた | 書きたい場面を先に書く。順番通りに書く必要はない |
| 他の作品を書きたくなった | 短編として書いて発散する。長編を二本並行させない |

### 「休載」の作法

止まるときは、必ず告知する。

- 「〇月まで休載します」と期限を切る
- 「不定期になります」と正直に言う
- 何も言わずに消えるのが、読者にとって最悪である

**告知して休んだ連載は、再開したときに読者が戻ってくる。** 無言で消えた連載は戻ってこない。

### 完結という価値

WEB小説の世界では、**完結させること自体が希少価値**である。

- 書籍化・コミカライズの判断において、完結作品は有利に働く
- 読者は「完結済み」を検索条件にする
- 何より、**一本完結させた書き手は、次の作品を確実に完結させられる**

100話の未完より、30話の完結のほうが価値がある。**最初の一本は、短くてよいから完結させる**ことを強く推奨する。

## 11-11　ケーススタディ ―― 企画の実例

本章の手順を使って、四つの企画を組み立ててみる。実際に書くかどうかは別として、**手順の適用例**として読まれたい。

### ケース1：追放もの × 生産 × 現代知識

- **コンセプト**：「〈記録〉スキルしか持たず追放された青年が、辺境で世界初の帳簿と統計を作り、領地経営を変える話」
- **エンジン**：ざまぁ（前半）→ 内政の蓄積（後半）
- **差別化**：能力軸。戦闘力ゼロ、記録能力のみ。**会計・統計という現代知識**
- **終わり方**：辺境が交易の中心地になり、追放した側が取引を求めて訪れる状態
- **ポイント**：ざまぁで引き込み、内政で持続させる（→第3章3-6の分業原理）

### ケース2：悪役令嬢 × 職能 × 一途

- **コンセプト**：「断罪される運命の令嬢が、破滅回避を諦めて薬師として身を立てることにしたら、なぜか国中の病を救ってしまう話」
- **エンジン**：承認（能力を認められる）＋ 溺愛（一人の相手）
- **差別化**：目的軸。**破滅回避ではなく、破滅の受容から始まる**
- **終わり方**：令嬢が自分の意思で立場を選び直している状態
- **ポイント**：定番の様式を使いながら、目的だけを反転させる

### ケース3：現代ダンジョン × 職業 × 中年

- **コンセプト**：「45歳のビルメンテナンス業者が、ダンジョンの清掃・保守を請け負ううちに、誰も知らない構造を理解してしまう話」
- **エンジン**：発見と謎解き＋ 職能による承認
- **差別化**：主人公軸。**戦わない、中年、専門職**
- **終わり方**：ダンジョンの正体が明かされ、主人公が社会的な役割を得ている状態
- **ポイント**：作者の実務知識が活きる領域を選ぶ

### ケース4：転生 × 非人間 × 育成

- **コンセプト**：「使い魔の卵に転生した元保育士が、自分を孵した孤独な魔術師を育て直す話」
- **エンジン**：保護と成長（他者の成長を見る快楽）＋ 癒し
- **差別化**：関係軸。**主人公が主役ではなく、育てる側**
- **終わり方**：魔術師が独り立ちし、主人公が見送る状態
- **ポイント**：主人公の成長ではなく他者の成長を描く。喪失の予感が物語を駆動する

## 11-12　実践のまとめ ―― 20の指針

1. コンセプトを一行で書く
2. 快楽エンジンを一語で決める
3. 差別化は一点だけ
4. 終わり方（到達状態）を最初に決める
5. 第1話でタイトルの約束を果たす
6. 3話目までにエンジンを作動させる
7. 10話目までに中期目標を提示する
8. 1話は2,000〜3,000字、1話1イベント
9. 各話に引きを置き、種類を変える
10. 5〜10話に1回、他者視点を挟む
11. 段落は1〜3行
12. 能力には制約を、主人公には欠落を
13. 敵役には合理性を、かませには実力を
14. 貨幣と物価の表を作る
15. 設定資料（人物・固有名詞・時系列）を運用する
16. 20〜30話ストックしてから開始する
17. 続けられるペースを守る
18. 音読して推敲する
19. 止まるときは告知する
20. **完結させる**
