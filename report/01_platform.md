# 第1章　場が文法をつくる ―― 投稿プラットフォームの構造

> **本章の要点**
> WEB小説の「奇妙な作法」は、すべて場の制度設計から演繹できる。長いタイトルはランキング一覧という**検索UI**への適応であり、冒頭即転移は**離脱率**への適応であり、短い章は**スマホの縦スクロール**への適応であり、テンプレ設定は**説明コストの圧縮**への適応である。制度を理解すれば、文法は暗記するものではなく、導出できるものになる。

---

## 1-1　前史 ―― WEB小説はどこから来たか

### 1-1-1　個人サイトとテキスト系文化（1990年代後半〜2000年代前半）

インターネット上の日本語小説は、投稿サイトよりも先に**個人サイト**として存在していた。ジオシティーズや infoseek のホームページスペースに、HTMLを手打ちして小説を掲載する。読者は掲示板やメールで感想を送る。作品の発見は、リンク集、Web拍手、テキストサイト同士の相互紹介によって行われた。

この時代の重要な特徴は、**発見の仕組みが人間関係だった**ことである。ランキングという中央集権的な発見装置は存在せず、したがって「ランキングに最適化する」という発想も生まれない。読者は少数だが濃密で、作者は自分の書きたいものを書いた。長さも形式も自由だった。

### 1-1-2　二次創作の実験場 ―― Arcadia、暁、ハーメルン

2000年代前半、二次創作を扱う投稿サイト（「Arcadia」＝旧・理想郷、「暁」、のちの「ハーメルン」）が大きな書き手人口を抱えた。ここで培われた作法のいくつかは、のちのなろう系に直接流れ込んでいる。

- **クロスオーバー／憑依・転生の技法**――既存作品世界に現代人が転生・憑依する形式は、二次創作で徹底的に洗練された。「原作知識を持つ主人公」という構図は、のちの「乙女ゲーム転生」「原作知識チート」の直接の祖先である。
- **オリ主（オリジナル主人公）の文法**――既存世界に外部から来た主人公が、原作キャラクターと関係を結び、原作の悲劇を回避する。この「破滅回避」の物語形式が、悪役令嬢ものの骨格になった。
- **感想欄との共同制作**――読者の反応を見ながら次話を書く、という執筆スタイルは二次創作コミュニティで一般化していた。

**創作上の含意**：現在の「テンプレ」の多くは、著作権の制約がない自由な実験場で、何万回も試行錯誤された結果として磨かれた形式である。だからこそ効く。

### 1-1-3　ケータイ小説（2005〜2008年頃）

『Deep Love』『恋空』に代表されるケータイ小説は、**モバイル端末での読書に最適化された最初の日本語小説フォーマット**だった。一行が短く、改行が多く、会話中心で、地の文が少ない。段落は数行で切れる。

しばしば文学的に低く評価されたが、フォーマットとしての発明は決定的だった。**画面の狭さと縦スクロールに対する最適解**を、日本語の散文として最初に提示したのがケータイ小説である。現在のWEB小説の組版感覚――短い段落、多い改行、高い会話比率――は、直接にはこの系譜を引いている。

2010年代前半、投稿サイトのランキングからケータイ小説的作品が姿を消し、かわりに異世界ファンタジーが台頭する。だが**書式は残った**。内容は入れ替わり、器は継承されたのである。

## 1-2　「小説家になろう」という装置

### 1-2-1　成立と制度化

「小説家になろう」は2004年に個人サイトとして開設され、規模の拡大にともない2010年に法人化（株式会社ヒナプロジェクト）された。運営の基本方針は一貫して「**場の提供に徹する**」ことにあり、編集による選別も、公式なジャンル誘導も、原則として行わない。作品の価値は、読者の投票行動によってのみ決まる。

この「編集不在」という設計は、二つの重大な帰結をもたらした。

**帰結①：品質の分散が極端に大きくなる。**
プロの編集による足切りがないため、投稿作の平均品質は低い。しかし同時に、既存の商業的判断では通らない実験も生き残れる。「もしゲームのステータス画面をそのまま小説に出したら？」という発想は、商業編集者なら止めただろう。だが、なろうでは読者が是と判断した。

**帰結②：発見装置がすべてを決める。**
編集者がいない以上、読者と作品を結びつけるのはランキングとタグ検索だけである。この装置の設計が、事実上の**編集方針**として機能した。

### 1-2-2　ランキングという編集者

「小説家になろう」のランキングは、2010年末から2011年にかけて段階的に整備され、2012年末には日間・週間・月間・四半期・年間・累計という時間軸別のランキングが出そろった。総合ランキングとジャンル別ランキングが併存し、上位100作品が一覧表示される。

評価の基礎になるのが**ポイント**である。おおよそ次の構造をとる（細部は時期により変更されている）。

```
総合ポイント ≒ ブックマーク数 × 2 ＋ 評価ポイント（文章評価＋ストーリー評価）
```

この式は単純だが、そこから導かれる帰結は深い。

**帰結①：ブックマークの重みが大きい。**
評価（星）を入れるにはログインして能動的に採点する必要があるが、ブックマークは「続きを読みたい」という**軽い意思表示**で押される。したがって、作品は「読み切りとして完成度が高い」よりも「**続きが気になる**」ことで報われる。連載の引きが重視される構造的理由がここにある。

**帰結②：ランキングは加速度を測る。**
日間ランキングは「その日に得たポイント」で決まる。つまり測っているのは総量ではなく**増分**である。更新すれば読者が戻ってきてブックマークが増え、ポイントが伸び、ランキングが上がり、新規読者が流入して、さらにブックマークが増える。この**正のフィードバックループ**が、「毎日更新」という執筆習慣を制度的に強制した。

**帰結③：ランキングは勝者総取りに近い。**
上位100位までしか一覧に載らない。101位と1位のあいだの露出量の差は、作品の質の差とはまったく釣り合わない。この非線形性が「まずランキングに入るための設計」を合理的な戦略にした。

> **創作への含意**
> ランキング上位作を分析するとき、「この作品が優れているから上位なのだ」と読むのは半分しか正しくない。より正確には「**この作品はランキングというアルゴリズムと相性が良い**」である。だから、上位作から学ぶべきは物語の内容だけでなく、**更新リズム、引きの位置、初速の作り方**でもある。

### 1-2-3　ジャンル区分の設計と、2016年の再編

「小説家になろう」のジャンル区分は、単なる分類ラベルではない。**ジャンル別ランキングが存在する以上、ジャンル選択は競争相手の選択である**。

現在の区分は、大ジャンル（恋愛／ファンタジー／文芸／SF／その他）の下に中ジャンルを置く二階層構造をとる。おおよそ次の通り。

| 大ジャンル | 中ジャンル |
|---|---|
| 恋愛 | 異世界〔恋愛〕／現実世界〔恋愛〕 |
| ファンタジー | ハイファンタジー〔ファンタジー〕／ローファンタジー〔ファンタジー〕 |
| 文芸 | 純文学／ヒューマンドラマ／歴史／推理／ホラー／アクション／コメディー |
| SF | VRゲーム／宇宙／空想科学／パニック |
| その他 | 童話／詩／エッセイ／リプレイ／その他 |
| ノンジャンル | ノンジャンル |

2016年頃に行われたこの区分の再編は、実は流行の地形を大きく変えた。とくに重要なのが、**「異世界〔恋愛〕」という区画の独立**である。それまで恋愛作品は男性向けファンタジーと同じ土俵で競っていたが、専用ランキングを得たことで、女性向け異世界もの――悪役令嬢、婚約破棄、聖女、追放令嬢――が**独自の生態系として自立**した。2017年以降の女性向けジャンルの爆発的成長は、この制度変更を抜きには説明できない。

同様に「ハイファンタジー（異世界が舞台）」と「ローファンタジー（現実世界が舞台に魔法等が入る）」の分離は、後年の「現代ダンジョン」ジャンルの受け皿を用意することになった。

> **創作への含意**
> ジャンル選択は「作品がどれに当てはまるか」ではなく「**どのランキングで戦うか**」の戦略的決定である。同じ作品でも、激戦区のハイファンタジーに置くか、相対的に競争の緩いジャンルに置くかで、露出はまったく変わる。

### 1-2-4　タグ（キーワード）システム

作品にはキーワード（タグ）を付与でき、読者はこれで検索・絞り込みを行う。「R15」「残酷な描写あり」といった注意喚起タグのほか、「異世界転生」「チート」「ざまぁ」「主人公最強」「スローライフ」「悪役令嬢」など、**ジャンルよりも細かい実効的な分類**がここで運用される。

重要なのは、タグが**双方向の約束**として機能していることだ。読者にとっては「この作品にはこれがある／ない」の保証であり、作者にとっては「この読者層に届ける」宣言である。「ざまぁ」タグを付けた作品でざまぁが起きなければ、読者は裏切られたと感じる。逆に、鬱展開を含む作品に警告タグがなければ、低評価が入る。

タグ文化は、**期待値の事前調整装置**である。これは商業出版における「レーベルの色」に相当する機能を、粒度をはるかに細かくして実装したものと理解できる。

## 1-3　主要プラットフォームの比較 ―― 場ごとに文法は違う

「WEB小説」を一括りにするのは誤りである。サイトごとに制度が違い、制度が違えば生まれる作品も違う。

### 小説家になろう

- **強み**：異世界ファンタジーの圧倒的な集積。書き手・読み手ともに最大規模。書籍化のスカウトが常時見ている。
- **制度の特徴**：ポイント＝ブックマーク×2＋評価。ランキング一覧の露出が絶大。金銭的還元は原則なし（書籍化がゴール）。
- **文法への影響**：長期連載・毎日更新・高速な導入・テンプレ共有。**「ランキング最適化」がもっとも強く働く場**。

### アルファポリス

- **強み**：閲覧数に応じたポイント制度と、自社出版レーベルへの直結。女性向け恋愛、悪役令嬢が特に強い。
- **制度の特徴**：**投稿者への金銭的インセンティブが制度化されている**点が独特。書籍化の意思決定も自社完結が多い。
- **文法への影響**：PV最適化――つまり「話数を多く、1話を短く」という圧力が働きやすい。

### エブリスタ

- **強み**：ケータイ小説文化の直系。ホラー、恋愛、短編。スマホ読者比率が高い。
- **制度の特徴**：多様なリアクション機能（ページ単位のスタンプ等）。
- **文法への影響**：**1話あたりの文字数がさらに短い**。会話主体・改行過多の組版。

### カクヨム

- **強み**：KADOKAWA運営。コンテスト（カクヨムWeb小説コンテスト等）が明確な登竜門として機能。
- **制度の特徴**：★評価とフォロー、レビュー機能。編集部が主催するコンテストという「人間の選別」が併存する。
- **文法への影響**：純粋なランキング最適化から相対的に自由。**現代もの、青春もの、実験的作品が成立しやすい**。なろうでは埋もれるタイプの作品の受け皿。

### ハーメルン

- **強み**：二次創作。オリジナルも受け入れる。
- **文法への影響**：原作知識を前提とした密度の高い書き方。**「読者が世界設定を既に知っている」状態での物語作法**の訓練場。

### ノベルアップ＋

- **強み**：ポイント還元型の収益モデル。ファンタジー中心。

### ノクターンノベルズ／ムーンライトノベルズ

- **位置づけ**：なろう系列のR18サイト。**ムーンライト（女性向け）は、悪役令嬢・溺愛系の重要な供給源**であり、ここ発の書籍化も多い。

### pixiv／pixivノベル

- **強み**：イラストとの近接。BL・百合・短編・SS。**キャラクター先行の創作文化**。

> **創作への含意（重要）**
> 「どこに投稿するか」は「どう書くか」と同じ重みを持つ決定である。現代恋愛の中編をなろうに置いても届きにくく、逆に王道異世界ハイファンタジーの長期連載をカクヨムだけに置くのは機会損失になりうる。**多重投稿（同一作品を複数サイトに掲載）は多くのサイトで許容されている**ので、主戦場を一つ決めたうえで、性質の異なるサイトにも展開するのが実務的な最適解である（各サイトの規約は必ず確認のこと）。

## 1-4　読書環境の物理学 ―― スマートフォンという制約

WEB小説の文法を規定するもう一つの要因が、**読書デバイス**である。

2012年前後に投稿サイトのスマートフォン対応が進み、読者の主力は PC からスマホに移った。この移行がもたらした制約は、次の四点に集約できる。

**（1）一画面の情報量が少ない。**
文庫本の1ページが約600字なのに対し、スマホの1画面は300〜400字程度。長い段落は「文字の壁」として認識され、スクロールする前に離脱される。→ **短い段落、多い改行**。

**（2）読書が細切れになる。**
通勤電車、休憩時間、就寝前。1回の読書セッションは5〜15分程度。→ **1話2,000〜4,000字**という標準的な話数の長さ。これは「1セッションで1〜2話読める」設計である。

**（3）戻り読みが難しい。**
紙の本なら数十ページ前の伏線を確認できるが、スマホの縦スクロールでは事実上不可能。→ **重要な情報は反復される**。キャラクターの能力や関係性は、必要になるたびに再説明される。これは冗長ではなく、メディアへの適応である。

**（4）並行して大量の作品が候補にある。**
無料で、指一本で別の作品に移れる。→ **離脱率との戦い**。冒頭で掴めなければ二度と戻ってこない。

この四点から、次の実務的な指針が導かれる。

| 制約 | 具体的な作法 |
|---|---|
| 一画面が狭い | 1段落は1〜3行。地の文が5行続いたら会話か改行を入れる |
| 細切れ読書 | 1話2,000〜4,000字、1話1イベント、末尾に引き |
| 戻り読み困難 | 固有名詞は初出時＋再登場時に短い説明を添える |
| 離脱自由 | 第1話の冒頭数百字で「この作品が何であるか」を提示する |

## 1-5　場の制度から、文法を導出する

本章の締めくくりとして、序章のテーゼ1「場が文法をつくる」を、具体的に演繹してみせよう。よく揶揄される「なろう系の特徴」は、すべて制度から導ける。

| 「特徴」 | 制度的な原因 |
|---|---|
| タイトルが異様に長い | ランキング一覧では**タイトルとあらすじ冒頭しか見えない**。表紙も帯もない。タイトルが唯一の広告枠なので、内容・ジャンル・約束をすべて詰め込む |
| 第1話で即座に異世界へ行く | 離脱率との戦い。「異世界ものを読みに来た読者」を待たせると、期待外れと判断されて離脱される |
| ステータス画面が出る | 能力を数値で示すのが**最短の説明**。しかも読者は既にゲームで慣れている。共有知識による説明コストの圧縮 |
| 主人公が強い | ストレス回避。無料で並行候補が多い環境では、不快な展開は離脱理由になる |
| 説明的な地の文が多い | 戻り読みができないので、反復説明が必要 |
| 1話が短い | スマホの1セッションに合わせている |
| 更新が毎日 | 日間ランキングが増分を測るため |
| テンプレ設定を使う | 説明を省いて差別化部分に文字数を投下するため |
| 章タイトルが説明的 | 目次一覧から読み返す読者への配慮。また未読者への広告 |

この表を逆から読めば、**制度が変われば文法も変わる**ことがわかる。実際、コンテスト主導のカクヨムでは長文タイトルの圧力が相対的に弱く、収益がPV比例のアルファポリスでは話数分割の圧力が強い。海外のウェブトゥーン市場を狙う場合は、また別の最適化が働く。

> **本章の結論**
> WEB小説の作法は「レベルの低い書き方」ではなく、**特定の環境における最適化の産物**である。したがって創作者が問うべきは「テンプレに従うべきか」ではなく、「**自分が戦う場の制度は何を報酬として与えるか**」である。制度を読み違えたまま良い物語を書いても、届かない。制度を理解したうえで、その制度が要求する最低条件を満たしたところから、初めて差別化が始まる。
