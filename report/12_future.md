# 第12章　これから ―― 2026年以後の展望

> **本章の要点**
> 予測は難しいが、**構造的に確定していること**と**変化の兆候**は区別できる。本章では、確定要因を土台に、今後数年に起こりうる変化を五つの軸で整理し、書き手にとっての戦略的な含意を導く。
>
> **注記**：本章は分析にもとづく推測であり、断定ではない。

---

## 12-1　構造的に確定していること

まず、当面変わらないと考えられる条件を確認する。

**（1）スマートフォンでの読書が主である。**
デバイスが変わらない限り、短い段落、細切れのセッション、離脱の容易さという条件は続く。したがって、第8章で述べた組版と語りの作法は、当面有効である。

**（2）無料が入口である。**
日本のWEB小説市場は、無料連載を発見装置とする構造を維持している。有料化・収益還元の比重は増しているが、無料の投稿サイトが新人の入口である構造は変わらない。

**（3）ランキングは残る。**
発見の問題を解決する装置として、なんらかのランキング／レコメンドは必須である。形式は変わっても（アルゴリズム推薦への移行）、**「発見される少数と、されない多数」という非対称は残る**。

**（4）コミカライズ経済は続く。**
電子コミック市場の規模と、IPを求める産業の需要は、当面続くと見られる。したがって「マンガ原作としての適性」は、書き手にとって重要な変数であり続ける。

**（5）供給される快楽の核は変わらない。**
承認、有能感、所属、安全、報復的正義（→第2章2-7）。これは人間の欲求に根ざしており、包装が変わっても中身は変わらない。

---

## 12-2　変化の五つの軸

### 軸1：アルゴリズム推薦への移行

現在の発見装置は、**共通のランキング**（全員が同じ上位100件を見る）である。しかし、動画・音楽・SNSの各プラットフォームは、すでに**個別化された推薦**へ移行している。

WEB小説にこれが本格導入された場合、何が起きるか。

| 現在（共通ランキング） | 推薦型に移行した場合 |
|---|---|
| 上位への集中が極端 | 中間層の作品にも読者が届く可能性 |
| 「流行」が全員に共有される | 流行が細分化し、共有されにくくなる |
| ランキング最適化が有効な戦略 | 「特定の読者層への深い適合」が有効に |
| テンプレの同質化圧力が強い | ニッチな独自性が報われやすくなる |

**書き手への含意**：もしこの移行が進むなら、「万人受け」より「**特定の誰かに深く刺さる**」設計のほうが有利になる。これは長期的には、多様性の回復を意味しうる。

### 軸2：収益モデルの多様化

日本のWEB小説は、韓国型の課金モデルを部分的に取り込みつつある。プラットフォームによる収益還元、話単位の課金、サブスクリプション、ファン支援。

**含意**：書籍化だけがゴールではなくなる。「**100人の熱心な読者から直接支援を受ける**」というモデルが成立すれば、ランキング競争とは別の生存戦略が生まれる。ただし日本市場では無料文化が根強く、移行は緩やかだろう。

### 軸3：生成AIによる分化

第10章で述べたとおり、平均的な文章の生産コストは下がった。これがもたらすのは、**二極化**である。

```
【量の領域】AIが支配する
　テンプレをなぞるだけの作品、量産型、短期消費型
　→ 人間の書き手が競争しても勝てない

【質の領域】人間の書き手が残る
　固有の経験、独自の主題、一貫した世界の長期運用、読者との関係
　→ AIには蓄積できない
```

さらに、**読者の側にも変化が起きる**可能性がある。「人が書いた」ことが価値になる、という反動である。すでに一部のプラットフォームでAI利用の表示が議論されているのは、その兆候である。

**書き手への含意**：AIを道具として使うことは合理的である。ただし、**AIで代替可能な部分を作品の中心に置かない**。

### 軸4：国際化と、逆流

日本のWEB小説は翻訳を通じて海外に流通し、同時に韓国・中国の作品が日本に流入している。この双方向の流れは加速すると見られる。

**予測される影響**
- 現代ダンジョン、回帰（時間遡行）といった韓国型ジャンルの定着
- ウェブトゥーン化を前提とした原作設計の一般化
- 海外読者を意識した表現への配慮（文化的な描写、差別的表現）
- 逆に、日本的な要素（和風、繊細な関係描写、スローライフ）の輸出価値の上昇

### 軸5：ジャンルのライフサイクル

第2章2-7の法則を現時点に適用すると、

| ジャンル | 現在の段階（推定） |
|---|---|
| 異世界転生チート | ④再文脈化（様式として定着。単独では戦えない） |
| 追放もの | ④再文脈化（導入の一部品に格下げ） |
| 悪役令嬢 | ④再文脈化（女性向けの古典的様式） |
| 現代ダンジョン | ②増殖期〜③飽和の初期 |
| 配信・可視化された承認 | ②増殖期 |
| 回帰・ループ | ②増殖期 |
| スローライフ／癒し | ④安定（常時一定の需要） |
| 中華後宮・和風 | ②〜③ |

**予測**：現代ダンジョンが飽和したあと、次に来るものは何か。法則に従えば、**その「逆」または「一段深い欲求」**である。候補として、

- **現代のまま、ダンジョンなしで超常が制度化された世界**（能力が職業になっている社会）
- **異能を持たない主人公が、制度や知識で戦う物語**（無双の逆）
- **共同体・組織を主人公とする物語**（個人英雄譚の逆）
- **喪失と再建の物語**（獲得の逆。ポストアポカリプス、復興もの）
- **「もう成り上がらなくていい」物語のさらに先**――成り上がりも癒しも消費し尽くしたあとの、**関係と継承**を主題とする物語

いずれも推測にすぎないが、**「いま飽和しているものの逆を探す」という方法自体は、繰り返し有効である**。

## 12-3　二つのシナリオ

### シナリオA：緩やかな成熟

- ランキング型の発見装置が残りつつ、推薦が補助的に導入される
- 収益還元が徐々に拡大し、専業に近い書き手が増える
- ジャンルの細分化が進み、各ニッチに固定読者がつく
- コミカライズ経済が継続し、原作供給源としての地位が安定する
- **結果**：多様性が緩やかに回復し、市場全体は成熟する

### シナリオB：急速な再編

- 生成AIによる大量投稿が発見装置を機能不全にする
- プラットフォームが投稿の選別・審査を強化し、「開かれた場」の性格が薄れる
- 収益化された少数のプロ作家と、趣味の投稿者の分断が進む
- 国際的なプラットフォームが日本市場に本格参入する
- **結果**：現在の「誰でも書けて、誰でも発見されうる」構造が変質する

どちらに向かうかは、主にプラットフォームの制度設計にかかっている。**場が文法をつくる**という本レポートの第一テーゼは、未来についても同じように働く。

## 12-4　書き手にとっての戦略的含意

以上を踏まえ、これから書く人への実務的な指針を五つ挙げる。

**（1）テンプレは道具として使う。目的にしない。**
テンプレをなぞるだけの作品は、AIとの競争に晒される。テンプレの上に、自分にしか書けないものを載せる。

**（2）「自分にしか書けないもの」を具体的に特定する。**
抽象的な「作家性」ではなく、具体的な資源として。職業経験、地域の知識、身体的な体験、特定分野への偏執的な関心、家族や介護や病の経験、外国語、技術知識。**これらはAIが持たず、他の書き手も持たない**。

**（3）長期の運用能力を武器にする。**
一貫した世界を100話、200話にわたって矛盾なく運用する能力は、極めて希少である。設定資料の管理、伏線の回収、キャラクターの一貫性――これは技術であり、訓練で身につく。

**（4）読者との関係を資産と考える。**
発見装置が変化しても、既に自分を読んでいる読者は残る。10人、100人という単位でも、それは次作の初速になる。

**（5）完結させることを最優先にする。**
完結は、①作品の商業的価値を高め、②書き手の技術を確実に向上させ、③読者の信頼を作る。**未完の大作より、完結した中編を三本書いた書き手のほうが、五年後に強い。**

---

## 12-5　最後に、変わらないこと

技術も制度も市場も変わる。だが、この形式が二十年にわたって供給し続けてきたものは、驚くほど変わっていない。

それは、**「自分は正しく評価されていない」という感覚に対する、物語による応答**である。

社畜が転生し、無能と追放された者が真価を示し、悪役令嬢が断罪を覆し、底辺の探索者が最強になる。これらはすべて、**現実で承認されていない読者に、承認を供給する物語**である。

この需要は、社会が承認の不足を抱えている限り、消えない。舞台が異世界からダンジョンへ、ダンジョンからまた別の何かへ移っても、供給される栄養素は同じである。

だから、書き手が考えるべき問いは、最終的にこう定式化できる。

> **あなたは、誰の、どんな承認されなさに、どんな形で応えるのか。**

この問いに固有の答えを持つ作品は、流行が変わっても読まれ続ける。
