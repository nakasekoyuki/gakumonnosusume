# 第2章　歴代人気作の通史 ―― 六つの時代区分

> **本章の要点**
> WEB小説の二十年は、六つの時代に区切って理解できる。各時代には固有の「支配的な物語形式」があり、その交代には必ず**制度の変化**か**飽和による反転**という原因がある。本章はその因果の連鎖を追う。
>
> **注記**：年代・作品情報は公開情報にもとづく整理であり、連載開始年と書籍化年が資料により前後することがある。年次は「おおよその目安」として読まれたい（→[序章0-5](00_introduction.md)）。

---

## 2-0　時代区分の全体像

| 期 | 年代 | 呼称 | 支配的形式 | 転換の要因 |
|---|---|---|---|---|
| 第0期 | 〜2009 | 前史 | ケータイ小説・二次創作・個人サイト | ランキング未整備 |
| 第1期 | 2010〜2012 | ランキング成立期 | 異世界ファンタジー化の開始 | ランキング制度の導入、スマホ対応 |
| 第2期 | 2013〜2015 | 書籍化ブーム期 | 転生・チート・テンプレの確立 | 専門レーベルの一斉創刊 |
| 第3期 | 2016〜2018 | 分化期 | 女性向けの自立、追放ものの誕生 | ジャンル区分の再編、カクヨム参入 |
| 第4期 | 2019〜2021 | 産業化期 | コミカライズ主導、アニメ化サイクル完成 | 出版不況下でのIP需要、コロナ禍 |
| 第5期 | 2022〜2026 | 再編期 | 現代ダンジョン、短尺化、国際化、AI | 韓国型モデルの影響、生成AI |

## 2-1　第0期（〜2009年）：前史 ―― まだ「なろう系」はなかった

「小説家になろう」が2004年に開設された時点で、そこは**現在とはまったく別の場所**だった。ランキングは存在せず、投稿作の主流はケータイ小説的な現代恋愛、青春もの、ホラーであった。異世界ファンタジーは一ジャンルにすぎず、しかも当時のそれは「王道の剣と魔法」――ゲーム的というより、指輪物語やD&Dの遠い子孫としてのファンタジーだった。

この時期に決定的だったのは、サイトの外で起きた二つの現象である。

**（1）『ソードアート・オンライン』（2002年〜個人サイトで連載、2009年書籍化）**
投稿サイト発ではなく個人サイト発だが、「**ゲーム世界に閉じ込められる**」という設定を大衆化した意義は大きい。VRMMOという舞台装置は、「ステータス」「レベル」「スキル」を物語内で**自然に**扱う口実を与えた。のちに異世界転生ものは、この口実を捨てたまま道具だけを継承することになる。

**（2）二次創作コミュニティにおける「転生・憑依」技法の成熟**
既存作品の世界に現代人が転生し、原作知識を武器に破滅を回避する。この形式は二次創作の場で徹底的に磨かれ、著作権的制約のないオリジナル作品へと持ち出されたとき、「異世界転生」「悪役令嬢」という名前を得た。

> **この時期の教訓**：後年の「テンプレ」は、突然発明されたのではない。**自由な実験場で数千回の試行を経て蒸留された形式**が、制度の整備とともに主流に浮上したのである。

## 2-2　第1期（2010〜2012年）：ランキング成立と、ファンタジーへの傾斜

### 何が起きたか

2010年末から2011年にかけて、ランキング機能が段階的に導入された。同時期にスマートフォンが普及し、サイトのモバイル対応が進む。この二つが重なったとき、**ランキング上位のジャンル構成が急速に入れ替わった**。ケータイ小説的な現代恋愛が退き、異世界ファンタジーが台頭する。

理由は単純である。ランキングは「続きが読まれる作品」を報酬する。**長期連載に耐える世界を持つファンタジーは、短編的完結性の高い恋愛ものより、構造的に有利だった**。

### 時代を代表する作品群

- **『魔法科高校の劣等生』**（2008年頃連載開始／2011年書籍化）――WEB小説発の商業的成功を初期に示した作品。膨大な設定の作り込み、圧倒的に強い主人公、細密な戦闘描写。「主人公最強」の商業的可能性を証明した。
- **『ログ・ホライズン』**（2010年頃連載開始／2011年書籍化）――ゲーム世界に閉じ込められた人々が**社会と経済を再建する**物語。「異世界で内政をする」という後年の巨大な鉱脈を最初に掘り当てた一作。
- **『オーバーロード』**（2010年頃／2012年書籍化）――**プレイヤーキャラクターの姿のまま異世界に残された**という設定。悪の側に立つ主人公、圧倒的な力、そして「強すぎるがゆえの認識のズレ」というコメディ性。後年の「勘違い系」の源流の一つ。
- **『ゲート 自衛隊 彼の地にて、斯く戦えり』**（2000年代後半／2010年書籍化）――現代の組織・技術が異世界に持ち込まれる「文明格差もの」の代表。
- **『まおゆう魔王勇者』**（2010年前後）――掲示板発。魔王と勇者が対話し、戦争ではなく**経済と農業**で世界を変える。内政・技術チートの思想的な祖。

### この時期に確立された要素

| 要素 | 内容 |
|---|---|
| ゲーム的世界観の全面化 | レベル、スキル、ステータス、ギルドが「説明不要の共有語彙」になる |
| 長期連載の優位 | 100話、200話と続く作品がランキング上位を占める構造 |
| 主人公最強の許容 | 成長物語でなくてよい、という発見 |
| 内政・技術チート | 「戦闘以外での無双」という広大なサブジャンルの発見 |

## 2-3　第2期（2013〜2015年）：書籍化ブームと、テンプレの結晶化

### 何が起きたか

2012年から2015年にかけて、**WEB小説を専門に書籍化するレーベルが相次いで創刊**された。ヒーロー文庫（2012年頃）、MFブックス（2013年頃）、アース・スターノベル、GCノベルズ、カドカワBOOKS（2015年頃）、TOブックス、オーバーラップノベルス――いわゆる「なろう系レーベル」の第一波である。

この産業側の動きは、書き手の行動を劇的に変えた。**「ランキング上位に入れば本になる」という明示的な報酬構造**が成立したのである。趣味の投稿が、事実上の新人賞に変わった。

結果として起きたのが、**テンプレートの結晶化**である。何が売れるかが可視化されたため、成功した形式が高速に模倣・改良された。

### 時代を代表する作品群

**男性向けの基幹作品**

- **『無職転生 〜異世界行ったら本気だす〜』**（2012年11月頃連載開始／2014年書籍化）――本レポートが繰り返し参照する作品。ひきこもりだった中年男性が幼児として異世界に転生し、幼少期から青年期、家族の形成、喪失、再起までを稠密に描く。**「転生後の人生を一生分書く」というスケールの発明**であり、なろう史上最大の影響力を持つ一作とされる。テンプレ的要素（転生、チート的才能、ハーレム）を備えながら、主人公の欠落と成長を真正面から書いた点で、テンプレの上限を示した。
- **『転生したらスライムだった件』**（2013年頃連載開始／2014年書籍化）――**人外転生＋国づくり**。捕食して能力を得るという明快なシステム、仲間が増え続ける快感、国家運営への拡張。のちにコミカライズの巨大ヒットを経てアニメ化され、「なろう系＝転スラ」というイメージを世間に定着させた。
- **『盾の勇者の成り上がり』**（2012年頃／2013年頃書籍化）――**冤罪から始まる復讐と再起**。「不当に貶められた主人公が、真価を証明して見返す」という構図は、後年の「ざまぁ」「追放もの」の直接の祖型である。
- **『Re:ゼロから始める異世界生活』**（2012年頃連載開始／2014年書籍化）――**死に戻り（ループ）＋徹底した心理描写**。無力な主人公が繰り返し死に、精神的に摩耗しながら進む。「主人公最強」の逆を行き、それでも巨大な支持を得た点で、この時期の多様性を象徴する。
- **『この素晴らしい世界に祝福を！』**（2012年頃／2013年書籍化）――**脱力系パーティコメディ**。ポンコツな仲間たち、成功しない主人公、テンプレの自己パロディ。「シリアスでなくてよい」という許可を与えた。
- **『本好きの下剋上』**（2013年頃連載開始／2015年頃書籍化）――**本を作るために文明を積み上げる**物語。目的が明確で、達成が段階的で、しかも「読書」という主人公の欲望が一貫している。長期連載の設計として教科書的。
- **『ありふれた職業で世界最強』**（2013年頃）――**どん底からの再起＋ダークな強さ**。クラス転移＋いじめ＋奈落落下という導入は、以後の「追放」構造の変奏として反復された。
- **『デスマーチからはじまる異世界狂想曲』**（2013年頃）――ステータス表記を作中に大胆に組み込み、**ゲーム的UIの小説内表現**を普及させた作品として位置づけられる。
- **『月が導く異世界道中』**『**とんでもスキルで異世界放浪メシ**』（2016年頃）ほか――**旅・グルメ・スローライフ**系の広がり。

**女性向けの萌芽**

- **『乙女ゲームの破滅フラグしかない悪役令嬢に転生してしまった…』**（2014年7月〜2015年3月連載／2015年書籍化）――通称「はめふら」。乙女ゲームの悪役令嬢に転生した主人公が、破滅エンドを回避しようと空回りするうちに、なぜか全員に好かれてしまう。**「悪役令嬢」というジャンル名を大衆化した記念碑的作品**。
- **『薬屋のひとりごと』**（2011年頃連載開始／2012年頃書籍化）――中華風後宮を舞台とした薬師の推理譚。**女性向け＋中華風＋知的解決**という組み合わせが、後年の「後宮もの」ブームの源流になった。
- **『くま クマ 熊 ベアー』**（2014年頃）――**癒し系・非戦闘的な充足**という方向性。

### この時期に確立されたテンプレ

第2期は、以後十年を規定する「部品」がほぼ出そろった時期である。

1. **導入テンプレ**：死亡 → 女神との面会 → 能力付与 → 異世界へ
2. **能力テンプレ**：ステータス、スキル、鑑定、収納（アイテムボックス）
3. **序盤テンプレ**：森でスライム → 街へ → ギルドで冒険者登録 → 依頼
4. **関係テンプレ**：奴隷／獣人／エルフの少女を助けて仲間に
5. **拡大テンプレ**：仲間が増える → 拠点を得る → 領地・国家へ
6. **快楽テンプレ**：見下していた者が主人公の実力を知って驚愕する

> **重要な観察**：これらは個別に発明されたのではなく、**「説明せずに済ませられる」という一点で選抜された**。ギルドの説明が要らないから物語が早く進む。ステータスがあるから強さの説明が一行で済む。テンプレは怠惰ではなく**圧縮**である（序章テーゼ3）。

## 2-4　第3期（2016〜2018年）：分化 ―― 女性向けの自立と「追放」の誕生

### 何が起きたか

三つの変化が同時に起きた。

**（1）ジャンル区分の再編（2016年頃）**
「異世界〔恋愛〕」が独立した区画として設けられたことで、女性向け作品が男性向けファンタジーと別のランキングで競えるようになった。これは**女性向けWEB小説の自立宣言**に等しい。以後、悪役令嬢・婚約破棄・聖女・追放令嬢が独自のエコシステムを形成する。

**（2）カクヨムの参入（2016年）**
KADOKAWAが運営する投稿サイトが登場し、コンテスト型の登竜門が併設された。純粋なランキング競争とは別の評価軸（編集部の選定）が生まれ、なろうでは埋もれるタイプの作品――現代もの、青春もの、文体重視の作品――に道が開いた。

**（3）テンプレの飽和と「反転」**
第2期のテンプレが飽和した結果、**同じ快楽をより速く供給する形式**への圧力が生じた。その解答が「追放もの」である。

### 「追放もの」の誕生と論理

追放ものの基本構造は次の通り。

```
①主人公は「無能」と評価され、パーティ／家／組織から追放される
②実は主人公の能力こそが組織を支えていた
③追放した側は主人公不在で急速に凋落する
④主人公は外部で正当に評価され、成功する
⑤追放した側が謝罪・懇願に来るが、主人公は受け入れない（＝ざまぁ）
```

この構造の何が優れているのか。**冒頭から不当な扱いを提示できる**点である。従来の成り上がりものは、主人公が実力を示すまでに何十話も必要だった。追放ものは、**第1話で「不当な貶め」を設置し、第2〜3話で反転を約束する**。ランキングの初速競争において、これは決定的な優位だった。

追放ものは2017年頃に独立したジャンルとして自覚され、2018〜2020年にかけて爆発的に増殖した。タイトルに「追放された」「クビになった」「〜と言われたので」を含む作品が氾濫し、やがて飽和する。

### 「悪役令嬢」の展開

女性向けでは、悪役令嬢ものが同時期に多様な変奏を生んだ。

| 変奏 | 内容 |
|---|---|
| 破滅回避型 | 断罪エンドを避けるために奔走する（はめふら型） |
| ざまぁ型 | 冤罪で婚約破棄された令嬢が、真価を示して逆転する |
| 悪役に徹する型 | 破滅を受け入れ、悪役として生き切る |
| モブ転生型 | 主要キャラではなく脇役に転生し、外側から物語を観測する |
| 悪役令嬢＋最強型 | 令嬢が武力・魔力で圧倒する（男性向け要素の輸入） |
| ループ型 | 処刑された令嬢が時間を巻き戻してやり直す |

**構造的に重要なのは、悪役令嬢ものが「原作知識チート」の女性向け実装である**という点だ。主人公は未来を知っている。それは物語における最強の情報アドバンテージであり、同時に「知っているのに変えられない」という緊張も生む。

### その他の重要な動き

- **『陰の実力者になりたくて！』**（2018年頃）――**勘違い系の完成形**。本人は中二病の妄想を演じているだけなのに、周囲が本気で受け取り、世界が妄想通りに動いてしまう。メタ的な笑いと爽快感の両立。
- **『転生したら第七王子だったので、気ままに魔術を極めます』**（2017年頃）――**恵まれた地位からの気楽な特化**。「苦労なしで楽しむ」という2020年代的な感性の先取り。
- **『魔王学院の不適合者』**（2017年頃）――**格の提示に特化した構成**。毎話ごとに主人公の規格外さが示される。
- **『わたしの幸せな結婚』**（2018年頃）――**和風・シンデレラ・虐げられヒロイン**。女性向けの「癒しと救済」路線を象徴。
- **『二度目の人生を異世界で』をめぐる問題（2018年）**――作者の過去の発言が問題視され、アニメ化企画が中止された事案。**WEB小説の書き手にも公人としての振る舞いが求められる**という認識を業界に広げた分岐点である（詳細と教訓は第10章）。

## 2-5　第4期（2019〜2021年）：産業化 ―― コミカライズが主戦場になる

### 何が起きたか

この時期の最大の変化は、**WEB小説の商業的な主戦場が「文庫」から「コミカライズ」に移った**ことである。

理由は市場構造にある。ライトノベルの書籍市場が伸び悩む一方、電子コミック市場は急拡大していた。出版社にとって、WEB小説は「小説として売る商品」ではなく「**低リスクで検証済みのマンガ原作**」として価値を持つようになった。

この転換は、作品の設計にまで影響を及ぼす。

| 変化 | 内容 |
|---|---|
| ビジュアル映え | 「絵になる」シーン、印象的なキャラデザインが企画段階で重視される |
| エピソードの独立性 | 1話ごとに山場を作る構成が、マンガの1話単位に転写しやすい |
| 説明の削減 | マンガでは長い説明が困難なので、原作段階から視覚化しやすい設定が好まれる |
| 序盤の凝縮 | コミカライズは原作の序盤しか描かれないことが多く、序盤の完成度が勝負になる |

### アニメ化サイクルの完成

同時期、WEB小説発のアニメが年間の相当数を占めるようになる。『転生したらスライムだった件』（2018年〜）、『盾の勇者の成り上がり』（2019年〜）、『本好きの下剋上』（2019年〜）、『乙女ゲームの破滅フラグ…』（2020年）、『無職転生』（2021年）、『蜘蛛ですが、なにか？』（2021年）――WEB連載 → 書籍化 → コミカライズ → アニメ化 → 海外配信、という**標準的な出世コース**が確立した。

これにより、WEB小説は「マイナーな趣味」から「日本のアニメ産業の主要な原作供給源」へと地位を変えた。

### コロナ禍の影響（2020年）

在宅時間の増加により、投稿数・読者数がともに増えた。同時に、この時期の作品には**「癒し」「安心」「非競争」への志向**が強まる傾向が見られた。スローライフ、辺境開拓、料理、テイマー（従魔）、もふもふ――主人公が誰とも争わずに満たされる物語群である。

### 時代を代表する作品群

- **『蜘蛛ですが、なにか？』**（2015年頃連載／2015年書籍化、2021年アニメ）――**非人間一人称の極北**。蜘蛛のモンスターに転生し、独白とステータス表示だけでサバイバルを進行させる。「地の文が独りごとでも物語は成立する」ことを証明した。
- **『望まぬ不死の冒険者』**（2016年頃）『**転生したら剣でした**』（2015年頃）――人外・道具への転生の広がり。
- **『聖女の魔力は万能です』**（2016年頃）――**女性向け×職能もの**。戦闘ではなく薬草・治癒での価値証明。
- **『転生王女と天才令嬢の魔法革命』**（2019年頃）――女性同士の関係性を軸にした異世界もの。**百合の主流化**。
- **『氷剣の魔術師が世界を統べる』**『**没落予定の貴族だけど…**』など、学園＋隠された実力の変奏。

## 2-6　第5期（2022〜2026年）：再編 ―― 現代回帰、短尺化、国際化、そしてAI

### 傾向①　「現代ダンジョン」の台頭

2022年頃から、**現代日本にダンジョンが出現する**という設定が急速に増えた。異世界に行かず、スマホもコンビニも会社もあるまま、都市の地下に迷宮がある。

これは単なる新奇性ではなく、いくつかの構造的利点を持つ。

- **世界設定の説明が不要**（読者は現代日本を知っている）
- **格差と承認の物語が書きやすい**（探索者ランク＝社会的地位、実名報道、SNS、配信）
- **異世界転生の「やり直し」感がない**（人生をリセットせず、いまの自分のまま成り上がる）
- **貨幣・法律・企業といった現代的リアリティを利用できる**

背景には、韓国のWEB小説・ウェブトゥーンにおける「ヘンター（헌터＝ハンター）もの」の世界的成功がある。現代都市＋ゲート＋ランク制度＋成長システムという枠組みは、国境を越えて共有された。

### 傾向②　配信者・SNS・可視化された評価

2020年代の作品では、**主人公の実力が「配信」「SNS」「掲示板」を通じて可視化される**演出が顕著に増えた。第三者の反応を挿入する手法――掲示板回、視聴者コメント、実況――は、「すごさ」を直接描写せずに読者へ伝える効率的な装置である。

この技法自体は以前から存在した（「まとめサイト風」「ネット民の反応」回）が、2020年代には**構造の中心**に据えられる作品が増えた。承認の可視化は、現代の読者にとってもっともリアリティのある報酬形式になったといえる。

### 傾向③　短尺化と「即効性」の追求

読者の可処分時間をめぐる競争が激化し、「**何話目で気持ちよくなれるか**」がさらに前倒しされた。第1話でスキルを得て、第2話で見返し、第3話で称賛される、という圧縮が進む。同時に、長大な世界設定を前提とする重厚な作品は、WEB連載よりも書籍・コミカライズ側で消化される傾向が強まった。

### 傾向④　女性向けの成熟と細分化

悪役令嬢は「テンプレ」を通り越して**古典的様式**になり、その上で細分化が進んだ。溺愛、政略結婚、契約結婚、年の差、義理の家族、幼女、モフモフ、和風、中華後宮、ゴシック、ざまぁ純度100%の短編――女性向け市場は男性向けより速く回転し、より多様な下位区分を維持している。

### 傾向⑤　生成AIの登場（2023年〜）

大規模言語モデルによる文章生成が実用段階に入り、投稿サイトは対応を迫られた。AI生成作品の投稿可否、表示義務、大量投稿への対策などが議論の対象となっている。同時に、書き手にとってはプロット補助・推敲・設定管理のツールとしての利用も広がった。

創作上の含意は逆説的である。**平均的な文章の生産コストがゼロに近づくほど、平均的でない要素の価値が上がる**。すなわち、独自の観察、具体的な体験知、特異な世界観、そして「この人が書いた」という作家性が、相対的に希少になる。

### 傾向⑥　国際化とウェブトゥーン

日本のWEB小説は、翻訳を通じて英語圏・中国語圏・韓国語圏へ流通している。同時に、韓国発のウェブトゥーン産業モデル（原作小説 → ウェブトゥーン → 多言語配信）が日本にも導入され、**縦スクロールマンガ化を前提とした原作**という新しいカテゴリが生まれつつある。

## 2-7　通史から読み取れる四つの法則

### 法則1｜ジャンルは四段階のライフサイクルをたどる

```
①発見期  ある形式が偶然のヒットとして現れる（原型作品）
②増殖期  模倣作が大量に生まれ、形式が「テンプレ」として言語化される
③飽和期  読者が飽き、パロディ・自己言及・逆張りが現れる
④再文脈化 形式が「様式」として定着し、他の要素と組み合わされて生き残る
```

追放ものは2017年に①、2018〜2020年に②、2021年頃に③、以後④として「他ジャンルの導入部の一部品」に格下げされた。悪役令嬢は2014年に①、2016〜2019年に②、2020年前後に③を経て、現在は④の様式として安定している。

> **予測に使う方法**：いま③の段階にあるジャンルを探し、その「逆」あるいは「一段深い欲求」を考える。追放ものが飽和したとき現れたのは、「追放されない」＝最初から評価されている主人公（第七王子型）と、「追放が些事にすぎない」＝もっと大きな目的を持つ主人公だった。

### 法則2｜制度変更はジャンルを生む

2016年のジャンル区分再編が女性向け市場を自立させたように、**プラットフォームのUI・分類・アルゴリズムの変更は、必ず新しい生態的地位（ニッチ）を作る**。書き手にとっては、制度変更の直後が最大の機会である。

### 法則3｜供給される快楽は不変で、その包装が変わる

二十年を通じて、供給されている快楽の核はほとんど変わっていない。

- **承認**（正しく評価されること）
- **有能感**（自分の能力が世界に効くこと）
- **所属**（居場所と仲間を得ること）
- **安全**（脅かされないこと）
- **報復的正義**（不当な相手が報いを受けること）

変わったのは、これらをどの舞台装置で、どれだけ速く供給するかである。異世界転生、追放、悪役令嬢、現代ダンジョン――すべて同じ栄養素の異なる調理法だと理解すると、流行の移り変わりが見通しやすくなる。

### 法則4｜先行者の遺産は「説明の省略」として蓄積する

『ログ・ホライズン』が内政を、『デスマーチ』がステータス表記を、『はめふら』が悪役令嬢を、それぞれ読者に教えた。以後の作品は、それらを**説明せずに使える**。WEB小説の歴史とは、共有語彙が積み上がっていく歴史でもある。新規参入者にとって、この蓄積は資産であり、同時に「知らないと読者と話が通じない」という参入障壁でもある。
