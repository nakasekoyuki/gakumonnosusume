# 第9章　読者と市場 ―― 数字とビジネスの構造

> **本章の要点**
> WEB小説は、無料の趣味投稿でありながら、明確な産業構造を持つ。ポイントの分布は極端なべき乗則に従い、上位のごく一部が露出のほぼすべてを獲得する。そして2020年代における最大の商業的出口は、書籍でもアニメでもなく**コミカライズ**である。この構造を理解しないまま「書籍化を目指す」と言っても、目標として機能しない。
>
> **注記**：本章の数値は公開情報にもとづく概算であり、実際の契約条件・部数は個別に大きく異なる。目安として読まれたい。

---

## 9-1　読者層 ―― 誰が読んでいるのか

正確な統計は公開されていないが、作品内容、感想欄の言説、書籍市場の動向から、おおよそ次のような像が推定される。

**男性向け（ハイファンタジー系）**

- 中心層は10代後半〜40代。とくに20〜30代の比重が大きいと見られる
- 就労経験のある層が主要な読者であることは、「社畜転生」「ブラック企業からの解放」というモチーフの頻出から強く示唆される
- ゲーム（とくにRPG・MMO）の経験を共有している

**女性向け（異世界恋愛系）**

- 中心層は10代後半〜40代。書籍・コミック市場では女性読者の購買力が高い
- 乙女ゲーム、少女漫画、BL等の隣接文化を共有している
- 「働く女性」の視点が作品に反映されることが多い（有能令嬢もの、経営もの）

**共通する特徴**

- スマートフォンでの読書が主
- 無料であることが前提。ただし気に入った作品には書籍・コミックで支払う
- **複数作品を並行して読む**。一作品への忠誠度は低いが、追いかけている作品数は多い

> **創作への含意**：読者は「小説を読む人」というより、「**可処分時間のなかで娯楽を消費する人**」である。競合はほかのWEB小説だけでなく、動画、ゲーム、SNSである。この認識は、テンポと快楽密度への要求を説明する。

## 9-2　ポイントの分布 ―― 極端な不平等

### べき乗則

投稿サイトにおける作品ごとのポイント分布は、典型的な**べき乗則（ロングテール）**に従う。具体的な数字は時期により異なるが、おおよその構造は次の通り。

```
投稿作品全体（数十万〜百万作品規模）
　├ 上位0.01%（数十作品）      ：数十万ポイント。歴史的な代表作
　├ 上位0.1%（数百作品）        ：数万ポイント。書籍化ほぼ確実
　├ 上位1%（数千作品）          ：数千ポイント。書籍化の可能性あり
　├ 上位10%（数万作品）         ：数百ポイント。固定読者がつく
　└ 残り90%                     ：数十ポイント以下。ほぼ読まれない
```

**この分布から導かれる、直視すべき事実**

1. **大多数の作品は読まれない。** これは作品の質だけの問題ではなく、発見されないことの問題である
2. **上位に入ることの価値は非線形。** 100位と1000位のあいだの露出差は、10倍ではなく100倍以上になりうる
3. **初速が累積優位を生む。** 早期にポイントを得た作品はランキングに載り、さらに読まれる（マタイ効果）

### 初速の重要性

日間ランキングは、その日に獲得したポイントで決まる。ここに載れば新規読者が大量に流入し、ブックマークが増え、翌日も載る。この**正のフィードバック**に入れるかどうかが、作品の運命を大きく分ける。

初速を作るための実務的な手段：

- **ストックを用意して連続更新する**（20〜30話）
- **1日複数回更新で、露出機会を増やす**
- **開始タイミングを選ぶ**（大型作品の連載開始直後を避ける等）
- **他サイトからの流入を作る**（SNS、既存作品からの誘導）
- **短編でヒットを作ってから、長編に誘導する**

ただし、**規約違反となる人為的なポイント操作は行ってはならない**。アカウント停止のリスクがあるだけでなく、業界内での信用を失う。

## 9-3　書籍化の実際

### スカウトのプロセス

WEB小説の書籍化は、多くの場合**出版社からの打診**で始まる。

```
①編集者がランキング・新着・タグ検索で作品を発見
②サイト内のメッセージ機能、または作者の連絡先へ打診
③条件の提示（レーベル、刊行時期、印税率、改稿の方針）
④契約
⑤改稿・書き下ろし（WEB版から加筆・修正されることが多い）
⑥イラストレーターの選定
⑦刊行
```

### 打診を受けやすくするために

- **連絡先を明記する**（多くの作者がこれを忘れる。メールアドレスまたはサイトのメッセージ受信を有効に）
- **完結、または継続の意思が明確である**（エタりそうな作品は打診されにくい）
- **一定の分量がある**（1冊分＝10万字前後は最低限必要）
- **タグ・ジャンルが明確**（編集者も検索で探している）

### 条件のおおよその相場

| 項目 | 目安 |
|---|---|
| 印税率 | 一般的な書籍と同水準（数%〜10%程度。契約により差がある） |
| 初版部数 | レーベル・作品による差が非常に大きい |
| 電子書籍 | 近年は電子の比重が大きく、契約の重要な部分 |
| 改稿 | 序盤の再構成、キャラクターの整理、加筆が求められることが多い |
| WEB版の扱い | 公開継続が基本だが、一部を非公開にする場合もある |

**注意すべき点（一般論として）**

- 契約書は必ず読む。**二次利用（コミカライズ、アニメ化、海外展開）の権利がどう扱われるか**が最重要
- 独占の範囲と期間
- WEB版の公開継続の可否
- 続刊の判断基準

契約に不安がある場合、専門家（弁護士、作家団体）に相談する選択肢がある。**「初めての書籍化で舞い上がって、内容を確認せずに署名する」ことが、後年の最大のリスク要因**である。

## 9-4　レーベル地図

WEB小説を主要な供給源とするレーベル群は、大きく二つのタイプに分かれる。

### 単行本型（いわゆる「なろう系レーベル」）

四六判・ソフトカバーの単行本形式。書き下ろしを含み、価格は文庫より高い。読者層はやや年上。

代表的なもの：MFブックス、カドカワBOOKS、オーバーラップノベルス、GCノベルズ、アース・スターノベル、TOブックス、HJノベルス、GAノベル、ヒーロー文庫、レジェンドノベルス、アルファポリスの各レーベルなど。

**特徴**：WEB小説を「そのままの形に近く」書籍化する。分量が多く、WEB版の読者がそのまま購入する構造。

### 文庫型（ライトノベルレーベル）

MF文庫J、電撃文庫、角川スニーカー文庫、ファンタジア文庫、ダッシュエックス文庫、GA文庫など。

**特徴**：WEB発の作品も扱うが、大幅な改稿を伴うことが多い。イラストの比重が高く、より若い読者層を想定。

### 女性向けレーベル

一迅社文庫アイリス、角川ビーンズ文庫、富士見L文庫、フロースコミック／FWコミックス系列、アリアンローズ、ベリーズファンタジー、PASH!ブックス、レジーナブックス（アルファポリス）など。

**特徴**：悪役令嬢・溺愛・異世界恋愛が中心。**コミカライズとの連動が特に強い**。

### レーベル選択の視点

書籍化の打診が複数来た場合、あるいは持ち込みを考える場合の判断材料：

- そのレーベルの既刊に、自作と近い作品があるか
- コミカライズの実績があるか（自社コミック媒体を持つか）
- 続刊の打ち切り基準（何巻まで出してもらえるか）
- 電子書籍・海外展開への積極性

## 9-5　コミカライズ ―― 2020年代の主戦場

### なぜコミカライズが中心なのか

日本の出版市場において、**電子コミックは長期の成長市場**である一方、文字ものの書籍市場は伸び悩んでいる。出版社にとって、WEB小説は次のように見えている。

```
WEB小説 ＝ 「読者の反応が既に検証済みの、マンガ原作の候補」
```

小説の書籍版は、しばしば**コミカライズへの導線**あるいは**原作の権利を確保する手段**としての性格を帯びる。実際、小説版の部数よりコミック版の部数が一桁多い、という事例は珍しくない。

### コミカライズを意識した設計

この構造を理解すると、原作段階での設計指針が見えてくる。

| 項目 | コミカライズに有利な条件 |
|---|---|
| **序盤の完成度** | コミカライズは原作の序盤しか描かれないことが多い。**最初の1〜2巻分が勝負** |
| **視覚的な見せ場** | 「絵で見たい」場面があるか。戦闘、変身、料理、建築、表情 |
| **キャラクターの外見的特徴** | 一目で識別できる差異（髪型、服装、種族的特徴） |
| **1話単位の山場** | マンガの1話（20〜30ページ）に変換しやすい構成 |
| **説明の少なさ** | 長い設定説明は、マンガでは処理が難しい |
| **会話の多さ** | ネームに変換しやすい |

**逆説的な観察**：WEB小説の「テンポ重視・説明控えめ・会話多め・1話1イベント」という作法は、**そのままマンガ原作としての適性**でもある。メディアへの適応が、偶然にも別のメディアへの適性を生んだ。

### ウェブトゥーン（縦スクロールマンガ）

韓国発の縦スクロール・フルカラー形式が日本にも定着しつつある。この形式は、

- スマートフォンでの読書に完全に最適化されている
- 多言語展開が容易（コマ割りの向きの問題がない）
- 制作がスタジオ分業型で、量産に向く

**創作への含意**：ウェブトゥーン化を前提とする場合、さらに「1エピソードあたりの情報量」が圧縮される。原作段階で、より短い単位の山場設計が求められる。

## 9-6　アニメ化の構造

### 標準的な経路

```
WEB連載 → 書籍化 → コミカライズ → （売上が一定水準を超える）
→ アニメ化企画 → 製作委員会の組成 → 放送 → 配信
```

アニメ化の判断は、**原作小説の部数よりも、コミック版の部数と電子の動き**に強く依存する傾向がある。

### アニメ化がもたらすもの

- 原作・コミックの部数が数倍に伸びる
- 海外配信による国際的な認知
- グッズ、ゲーム、舞台などの二次展開

### 作者にとっての現実

アニメ化は、作者個人の収入としては**必ずしも劇的な増加をもたらすとは限らない**。製作委員会方式では原作使用料の割合は限定的で、むしろ**原作とコミックの売上増**が主な恩恵になる。

また、アニメ化に伴い、作者は次のような負荷を負うことがある。

- 監修作業（脚本、設定、キャラクターデザインの確認）
- 取材・イベント対応
- **過去の言動への注目**（→第10章）

## 9-7　収益モデルの比較

WEB小説の書き手が金銭的な報酬を得る経路は、複数ある。

| 経路 | 内容 | 特徴 |
|---|---|---|
| **書籍化の印税** | 最も一般的 | 一発の額は大きいが、不確実 |
| **サイトの収益還元** | アルファポリス、ノベルアップ＋等 | 少額だが継続的。PV型 |
| **セルフパブリッシング** | Kindle Direct Publishing等 | 印税率は高いが、集客は自力 |
| **ファンからの直接支援** | pixivFANBOX、Fantia等 | 固定ファンがいれば安定 |
| **コミカライズ原作料** | 原作使用料＋印税の一部 | 近年は重要性が増している |
| **メディアミックス** | アニメ、ゲーム、グッズ | 到達する作品はごく少数 |

**現実的な見通し**：WEB小説の執筆だけで生計を立てられる書き手は、投稿者全体のごく一部である。一方で、**副業的な収入、あるいはキャリアの入口としての機能**は確実に存在する。「専業になれるか」ではなく「何を得たいか」を最初に決めておくことが、精神衛生上も重要である。

## 9-8　国際比較 ―― 韓国・中国のWEB小説産業

日本のWEB小説を相対化するために、隣接する二つの市場を簡単に見ておく。

### 韓国モデル

- **有料課金が早期から一般化**（話単位の課金、待てば無料）
- プラットフォームが**制作を主導**し、作家と契約する
- **ウェブトゥーン化が前提**の産業構造。小説→ウェブトゥーン→ドラマ／配信という一本道
- ジャンル：ヘンター（現代能力）もの、回帰（時間遡行）もの、悪役令嬢、武侠

**日本との差**：日本が「無料投稿→ランキング→書籍化」という**発見型**であるのに対し、韓国は「契約→制作→課金」という**生産型**に近い。作品の質のばらつきは韓国のほうが小さく、代わりに実験的な作品が生まれにくい。

### 中国モデル

- 巨大プラットフォームによる大規模な有料連載
- **極端な長編**（数百万字が珍しくない）
- 修真・仙侠・都市・歴史といった独自ジャンル体系
- ドラマ化・ゲーム化への強い接続

### 日本モデルの特異性

比較すると、日本のWEB小説の特異性が浮かび上がる。

1. **無料が原則である**（これは世界的に見ると珍しい）
2. **アマチュアの参入障壁が極端に低い**
3. **ランキングという単一の発見装置への依存が強い**
4. **書籍化がゴールとして共有されている**

この構造は、**多様性と偶然性を生む**という長所と、**書き手への金銭的還元が薄い**という短所を同時に持つ。2020年代には、日本でも収益還元型のモデルが徐々に増えており、この構造は変化しつつある。

## 9-9　市場から導かれる実務的示唆

1. **「書籍化」を目標にするなら、コミカライズ適性を意識する。** 序盤の完成度、視覚的見せ場、キャラの識別性。
2. **初速の設計は、作品の質と同じくらい重要**。ストックを持って始める。
3. **連絡先を明記する。** 打診が来ても届かなければ意味がない。
4. **完結させる。** 完結作品は、書籍化・コミカライズの判断において有利に働く。
5. **契約書を読む。** とくに二次利用権。
6. **複数の収益経路を知っておく。** 書籍化だけが道ではない。
7. **数字に振り回されすぎない。** べき乗則の世界では、ほとんどの作品が読まれない。それは書き手の価値の否定ではなく、発見装置の構造的な帰結である。
