# 付録B　WEB小説用語辞典

> 実際に書き手・読み手のあいだで使われている語を、七つの分野に分けて収録した。定義は流通している用法にもとづく整理であり、厳密な定義が存在しない語も多い。

---

## B-1　プラットフォーム・制度

| 用語 | 意味 |
|---|---|
| **小説家になろう（なろう）** | 2004年開設の小説投稿サイト。運営は株式会社ヒナプロジェクト。異世界ファンタジーの最大の集積地 |
| **ヒナプロジェクト** | 「小説家になろう」を運営する法人。2010年設立 |
| **カクヨム** | 2016年開設。KADOKAWA運営。コンテストが登竜門として機能 |
| **アルファポリス** | 投稿サイト兼出版社。閲覧数に応じた還元と自社レーベルへの直結が特徴 |
| **エブリスタ** | ケータイ小説文化の後継。ホラー・恋愛が強い |
| **ハーメルン** | 二次創作を中心とする投稿サイト |
| **ノベルアップ＋** | 2019年開設。収益還元型 |
| **ノクターンノベルズ／ムーンライトノベルズ** | なろう系列のR18サイト。ムーンライトは女性向け |
| **暁／Arcadia（理想郷）** | 2000年代の二次創作投稿サイト。多くの技法の実験場 |
| **ポイント** | なろうの評価指標。おおむね「ブックマーク×2＋評価点」 |
| **ブクマ（ブックマーク）** | お気に入り登録。ポイントの主要な源泉 |
| **評価点** | 読者による採点（文章・ストーリー）。ログインが必要 |
| **日間／週間／月間／四半期／年間／累計** | ランキングの集計期間。日間は「増分」を測る |
| **ジャンル別ランキング** | 大ジャンル・中ジャンルごとの順位。事実上の「戦場の選択」 |
| **キーワード（タグ）** | 作品に付与する分類語。検索・期待調整・警告の三機能 |
| **R15／R18** | 年齢制限の区分 |
| **残酷な描写あり** | 必須の警告タグの一つ |
| **感想欄** | 読者が話ごとにコメントを書き込む場 |
| **活動報告** | 作者が読者に向けて書く告知・雑記の機能 |
| **しおり** | 読んだ位置の記録機能 |
| **なろうコン／各種コンテスト** | サイト主催の賞。書籍化の別ルート |
| **多重投稿** | 同一作品を複数サイトに掲載すること（多くのサイトで許容） |
| **転載** | 他人の作品を無断で再掲載すること。明確な違反 |

## B-3　物語構造

| 用語 | 意味 |
|---|---|
| **引き** | 話の末尾に置く未解決。次話を読ませる装置 |
| **導入／掴み** | 冒頭で読者の関心を確保する部分 |
| **3話の壁／10話の壁** | 読者が継続を判断する典型的な地点 |
| **快楽エンジン** | 繰り返し作動して読者に報酬を与える構造（本レポートの用語） |
| **燃料** | エンジンが消費する要素（未知の強敵、侮る者、未取得のスキル等）（本レポートの用語） |
| **アーク／章** | 10〜40話程度のまとまり |
| **ラダー構造** | 目的をはしご状に更新していく長期連載の設計（本レポートの用語） |
| **インフレ** | 能力・敵の強さが際限なく上昇する現象 |
| **テンプレ** | 共有された定型。圧縮された共有知識 |
| **お約束** | テンプレのうち、読者が期待するもの |
| **フラグ** | 後の展開を予告する要素。「死亡フラグ」「恋愛フラグ」など |
| **フラグ回収** | 予告された展開が実現すること |
| **伏線** | 気づかれずに置かれ、後に意味が判明する要素 |
| **エタる** | 未完のまま更新が止まること（「永遠に続く」に由来） |
| **完結済み** | 物語が終わっていること。検索条件としても機能する |
| **書き溜め／ストック** | 公開前に用意した原稿 |
| **改稿** | 公開後、または書籍化に際しての書き直し |
| **加筆／書き下ろし** | 書籍化時にWEB版にない内容を加えること |
| **幕間（まくあい／インターミッション）** | 主筋から離れた挿話 |
| **視点切り替え／Side** | 主人公以外の視点で書かれる部分 |
| **他者視点** | 主人公を外から観測する視点。承認の供給に有効 |
| **掲示板回** | ネット掲示板の書き込み形式で第三者の反応を描く技法 |
| **総集編／設定回** | 情報整理のための話。読み飛ばされやすい |

## B-4　キャラクター

| 用語 | 意味 |

| **ロリババア** | 外見は幼く、実年齢が非常に高い長命種 |
| **獣人** | 動物的特徴を持つ種族 |
| **亜人** | 人間以外の人型種族の総称 |

| **師匠** | 技術と世界観を教える役。説明の正当化装置 |

| **元婚約者** | 女性向けにおける加害者・比較対象・ざまぁの受け手 |
| **攻略対象** | 乙女ゲーム由来。恋愛の相手役候補 |

## B-6　執筆・実務

| 用語 | 意味 |
|---|---|
| **一話** | 更新の単位。2,000〜3,000字が標準 |
| **毎日更新** | ランキング対策として有効な更新戦略 |
| **予約投稿** | 公開日時を予約する機能 |
| **プロット** | 事前の構成計画 |
| **設定資料** | 人物・固有名詞・時系列の管理表 |
| **表記ゆれ** | 同じ語の書き方が揺れること |
| **誤字報告** | 読者からの誤字指摘機能 |
| **推敲** | 公開前の見直し |
| **音読チェック** | 声に出して読み、詰まる箇所を探す推敲法 |
| **地の文** | 会話以外の文章 |
| **会話比率** | 全体に占める会話文の割合 |
| **一人称／三人称** | 語りの人称 |
| **心内語** | 登場人物の内面の声 |
| **ルビ** | 振り仮名。二重の意味づけにも使われる |
| **長文タイトル** | 内容を説明する長いタイトル。唯一の広告枠への適応 |
| **あらすじ** | 作品紹介文。タイトルの次に読まれる |
| **初速** | 連載開始直後のポイント獲得速度 |
| **埋もれる** | ランキングに載らず、読まれないこと |
| **PV** | ページビュー。閲覧数 |
| **UU** | ユニークユーザー数 |

## B-7　業界・ビジネス

| 用語 | 意味 |
|---|---|
| **書籍化** | 出版社から本として刊行されること |
| **スカウト／打診** | 編集者からの書籍化の申し出 |
| **なろう系レーベル** | WEB小説を主要な供給源とする単行本型レーベル群 |
| **コミカライズ** | 漫画化。2020年代における最大の商業的出口 |
| **ウェブトゥーン** | 縦スクロール・フルカラーの漫画形式 |
| **メディアミックス** | 複数媒体への展開 |
| **製作委員会** | アニメ製作の出資組織 |
| **原作使用料** | 二次利用に対する対価 |
| **印税** | 書籍の売上に応じた報酬 |
| **重版** | 増刷 |
| **打ち切り** | 続刊の中止 |
| **電子書籍** | 近年は売上の主要部分を占める |
| **セルフパブリッシング** | 自主出版（KDP等） |
| **二次利用権** | コミカライズ・アニメ化・海外展開などの権利。契約上の最重要項目 |
| **独占契約** | 他社への提供を制限する契約 |
| **IP（知的財産）** | 展開の元となる作品・キャラクター |
| **ノベライズ** | 逆方向（映像・ゲームの小説化） |
