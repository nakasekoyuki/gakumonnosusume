# WEB小説サーヴェイ・レポート
## 『なろう』以後の物語文法 ―― 歴代人気作から読み解くジャンル・構造・キャラクター・世界設定

**副題**：創作者のための実践的サーヴェイ

---

### 本レポートについて

日本語圏のWEB小説投稿サイト（「小説家になろう」を中心に、カクヨム、アルファポリス、エブリスタ、ハーメルン等）に発表され、歴代のランキング上位を占めてきた作品群を対象に、

- どのようなジャンルが、いつ、なぜ流行したのか
- 物語はどのような構造で組み立てられているのか
- キャラクターにはどのような類型と設計思想があるのか
- 世界設定はどのような「共有インフラ」の上に成り立っているのか
- そして、それらは創作の実践にどう応用できるのか

を包括的に整理した、新書一冊規模（本文・付録あわせて約10万字）のサーヴェイ・レポートです。

読者として想定しているのは、**これからWEB小説を書こうとする人、すでに書いているが伸び悩んでいる人、商業ラノベ／コミカライズ／アニメの企画に携わる人、そして現代の物語生態系を分析的に理解したい人**です。

### 通読の目安

- **全体を通読したい方**：序章 → 第1章 → 第2章 の順に読むと、全体の見取り図が得られます。
- **すぐ書きたい方**：第4章（構造）→ 第11章（実践）→ 付録C（テンプレ集）→ 付録D（ワークシート）。
- **分析・企画目的の方**：第2章（通史）→ 第3章（ジャンル）→ 第9章（市場）→ 第10章（批判）。
- **設定づくりに悩んでいる方**：第7章（世界設定）→ 付録B（用語）→ 付録D。

### 重要な注記

本レポートの数値・年代・作品情報は、公開情報および一般に流通している言説の整理にもとづく **二次的なサーヴェイ** です。調査環境の制約により一次データ（ランキングの生ログ、サイトAPI、出版部数の公式発表など）へ網羅的にアクセスすることはできていません。したがって、

- **年代・順位・部数などの具体的数値は「おおよその目安」** として扱ってください
- とくに部数・売上・ユーザー数は、出典によって数字が大きく異なります
- 傾向分析・構造分析（第3〜8章、第11章）が本レポートの主眼であり、そこに価値の重心があります

詳細は[序章](00_introduction.md)および[付録E](appendix_e_sources.md)を参照してください。
