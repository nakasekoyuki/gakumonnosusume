# 第7章　異世界のインフラ ―― 世界設定の作法

> **本章の要点**
> WEB小説の「異世界」は、作者ごとに一から創造されるものではない。**書き手と読み手のあいだで共有された、巨大なデフォルト設定**が存在し、各作品はそこからの差分として書かれる。この共有財を正確に把握することは、①説明を省いて筆を進めるため、②どこで差別化するかを見極めるため、の両面で不可欠である。

---

## 7-1　「デフォルト異世界」という共有財

### 標準仕様の目録

現代のWEB小説読者が、何の説明もなく受け入れる設定群を列挙してみよう。

**世界の骨格**

- 中世〜近世ヨーロッパ風の文明水準（剣、鎧、馬車、石造の街、城壁）
- 王国・帝国・公国からなる国際関係。皇帝、王、公爵、辺境伯といった爵位
- 魔物（モンスター）が生息し、人里の外は危険である
- 魔法が存在し、一定の体系を持つ

**制度**

- 冒険者ギルドがあり、ランク（F〜S、または銅〜白金）で実力が格付けされる
- 依頼（クエスト）を受け、報酬を得る
- 商業ギルド、職人ギルド、盗賊ギルドといった同業組織
- 教会があり、治癒魔法と社会福祉を担う

**個人の能力**

- レベルの概念があり、経験によって上昇する
- ステータス（HP、MP、力、敏捷、魔力……）が数値化されている
- スキル（技能）を習得できる。固有スキル、ユニークスキルが存在する
- 鑑定（アプレイザル）で他者・物品の情報を見られる
- アイテムボックス／収納で物を保管できる

**種族**

- 人族のほか、エルフ（長命・魔法・森）、ドワーフ（頑健・鍛冶・酒）、獣人（身体能力・耳と尾）、竜人、魔族
- 亜人差別が社会問題として存在する

**経済**

- 金貨・銀貨・銅貨の三〜四層の貨幣。おおむね「銅貨100枚＝銀貨1枚」的な単純な換算
- 宿屋一泊が銀貨数枚、といった相場感

**その他**

- 言語の問題は「なぜか通じる」「神の加護」「翻訳スキル」で処理される
- ポーション（回復薬）が流通している
- 魔石が魔物から採れ、エネルギー源・素材になる

### なぜこの標準ができたか

この共有設定の出所は、明確に**日本のコンピュータRPG**である。ドラゴンクエスト、ファイナルファンタジー、そのフォロワー群が、40年かけて日本人の「ファンタジー世界の常識」を統一した。さらにMMORPGが、ギルド・クエスト・ランク・スキルツリーといった**制度的な語彙**を追加した。

これは文学史的に見ると、驚くべき事態である。**特定の商業的娯楽形式が、一言語圏の想像力の共通基盤になった**。「異世界」という語で日本語話者が思い浮かべる像は、驚くほど均一である。

### 共有財としての意味

この標準化のもたらす利点は絶大である。

```
「彼はギルドで銅級から始め、三ヶ月でBランクに達した」
```

この一文が、説明なしで理解される。組織があり、階級があり、審査があり、通常はもっと時間がかかることまで伝わる。もし世界を一から作れば、同じ情報に数千字を要する。

> **テーゼ3の再確認**：テンプレ設定は制約ではなく、**圧縮アルゴリズム**である。作者は圧縮によって節約した文字数を、差別化したい部分に集中投下できる。

### 共有財の危険

一方で、危険もある。

1. **借り物であることを忘れる**――「ギルドとはそういうもの」と思考停止すると、世界に必然性が宿らない
2. **差別化の場所を失う**――全てを標準仕様にすると、作品を選ぶ理由がなくなる
3. **矛盾に気づかない**――ゲーム由来の制度は、社会として考えると不合理な点が多い（後述）

## 7-2　ステータスとスキル ―― 「ゲーム的リアリズム」の意味論

### ステータス表示は何をしているのか

作中にステータス画面が表示される、という技法は、しばしば「小説の作法として稚拙」と批判される。だが機能を分析すると、四つの仕事を同時にこなしていることがわかる。

| 機能 | 内容 |
|---|---|
| **①強さの客観化** | 「彼は強い」ではなく「攻撃力1200」。比較可能な尺度を与える |
| **②成長の可視化** | 数値が上がることで、進歩が実感される（ゲームの報酬設計と同型） |
| **③情報の圧縮** | 数十行の説明を、一つの表で代替する |
| **④異常性の即時伝達** | 「HP：999999」の一行で、規格外であることが伝わる |

とくに②は重要である。**小説において「成長」は本来、行動と判断の変化として描かれるべきものだが、それには膨大な紙幅を要する**。ステータス表示は、その成長実感を数行で供給する。効率という観点では、圧倒的に合理的な発明である。

### ステータス設計の実務

**（1）数値のスケールを最初に決める。**
一般人が10、熟練兵が100、英雄が1000、といった基準を決めておかないと、後半でインフレしたときに数値が意味を失う。

**（2）表示の頻度を制御する。**
毎話ステータスを貼ると、読者は読み飛ばす。**変化があったとき、または節目にだけ表示する**のが実務的。

**（3）ステータスが「見える理由」を設計する。**
誰でも見られるのか、鑑定スキルが要るのか、教会で測定するのか。ここに社会制度を接続すると、世界に厚みが出る（例：ステータス測定が成人の儀式であり、そこで人生が決まる社会）。

**（4）数値化できないものを残す。**
すべてが数値化されると緊張が消える。「数値では測れない何か」（経験、覚悟、相性、運）を残しておくと、格下が格上に勝つ展開が可能になる。

### スキル体系の設計パターン

| パターン | 内容 | 長所／短所 |
|---|---|---|
| **リスト型** | スキルが個別に存在し、習得していく | 単純。数が増えると管理が破綻 |
| **ツリー型** | 下位スキルから上位へ派生する | 成長の道筋が見える。設計コストが高い |
| **合成型** | 複数のスキルが融合して新スキルになる | 発見の快感。組み合わせ爆発に注意 |
| **成長型** | 使用によってスキル自体がレベルアップする | 継続的な報酬。細かい管理が必要 |
| **ユニーク型** | 主人公だけの固有スキル | 差別化に直結。**万能にすると物語が死ぬ** |
| **職業（ジョブ）型** | 職業が能力群を規定する | 社会制度と接続しやすい |

**設計上の助言**：スキルは「増やす」より「深める」ほうが物語になる。100種類のスキルを列挙するより、**1つのスキルの新しい使い方を10回発見する**ほうが、読者の満足度は高い。

## 7-3　冒険者ギルドという制度

### 標準的な仕様

- 誰でも登録できる（身分不問）。登録証（ギルドカード）が身分証を兼ねる
- ランク制（F/E/D/C/B/A/S など）で実力を格付け
- 依頼を掲示板に貼り出し、受注・達成・報告のサイクル
- 魔物の討伐証明（角、牙、魔石）の買取
- 素材・迷宮産物の換金
- 受付嬢がいる

### 制度としての機能

冒険者ギルドは、物語装置としてきわめて優秀である。

1. **主人公に社会的地位を与える**（身分がなくてもランクで評価される）
2. **依頼という形で物語を供給する**（次に何をするかが自動的に決まる）
3. **ランク上昇という成長指標を与える**（レベルとは別の社会的成長）
4. **観測者を常設する**（受付嬢、他の冒険者が驚く）
5. **世界の情報を集約する**（噂、依頼内容、他の冒険者の話）

### リアリティを高めるための問い

一方で、ギルドは社会制度として考えると不自然な点が多い。**そこを詰めると差別化になる**。

- ギルドの収入源は何か（依頼手数料？ 素材の転売？ 国からの補助？）
- 誰がランクを審査し、その基準は誰が決めるのか
- 国家とギルドの関係は（治外法権か、国の下請けか、対立関係か）
- 冒険者の死亡率は。保険は。遺族は
- 依頼を放棄した場合の罰則は
- 複数の国にまたがる組織なら、戦争時にどう振る舞うのか
- 冒険者という職業は、なぜ社会的に必要とされているのか

> **実例的な観察**：ギルドの制度設計に踏み込んだ作品は、それだけで印象に残る。「ギルドが国家に対して政治的な影響力を持つ」「ランクアップに政治的な意図が絡む」といった設定は、標準仕様からの差分として強く機能する。

### 冒険者ギルドを「使わない」という選択

近年、あえてギルドを出さない作品も増えている。代わりに、

- 軍・騎士団に所属する
- 商会・行商人として動く
- 貴族の家臣になる
- 教会・修道院に属する
- 探索者協会（現代ダンジョンもの）や、企業に雇用される

いずれも、ギルドと同じ機能（地位・依頼・成長・観測）を別の形で提供している。**機能を理解していれば、置き換えは自由である。**

## 7-4　経済 ―― 貨幣・物価・度量衡

### 標準的な貨幣体系

```
銅貨 → 大銅貨 → 銀貨 → 大銀貨 → 金貨 → 白金貨
（おおむね10倍または100倍刻み）

換算の目安（作品により差が大きい）
銅貨1枚 ≒ 100円
銀貨1枚 ≒ 1万円
金貨1枚 ≒ 100万円
```

### 物価の設計が生む効果

物価を具体的に決めておくと、**あらゆる場面の描写が具体化する**。

| 品目 | 目安 |
|---|---|
| パン1個 | 銅貨2〜5枚 |
| 宿屋一泊（素泊まり） | 銅貨50枚〜銀貨1枚 |
| 宿屋一泊（食事付き・中級） | 銀貨2〜3枚 |
| 鉄の剣 | 銀貨5〜20枚 |
| 一般的な家一軒 | 金貨20〜100枚 |
| 冒険者の日当（低ランク） | 銀貨1〜3枚 |

この表を作っておくと、「報酬は金貨5枚だ」という一行が、**読者にとって具体的な喜び**になる。逆に物価が不明なら、いくら貰っても感情が動かない。

> **実務的な助言**：物価表を作ることは、世界設定作業のうち**もっとも費用対効果が高い**作業の一つである。A4一枚で足りるが、効果は全編に及ぶ。

### 度量衡と暦

- 長さ・重さ：「メートル」「キログラム」をそのまま使う作品が多数派。独自単位を作ると読者の負担になる
- 時間：「一日」「一時間」はそのまま。ただし週・月・年の構成を変えると異世界感が出る（例：一年10ヶ月、一週間6日）
- 暦：建国紀元、神暦など。**歴史の深さを一語で示せる**便利な装置

### 経済リアリティの落とし穴

WEB小説でしばしば破綻するのが、**主人公が突然大金を得る場面**である。

- 中世的な経済で、金貨1000枚（＝現代換算10億円）を即金で支払える商人は存在するか
- 大量の魔物素材を売れば、市場価格は暴落しないか
- 現代知識で作った商品を売って独占的な利益を得るとき、既存業者はどう反応するか
- 貨幣の総量に対して、主人公の資産が大きすぎないか

こうした点を一度でも考えると、経済描写に説得力が生まれる。「**新技術を導入すると既存産業が反発する**」という展開は、内政ものの定番のドラマ源である。

## 7-5　魔法体系の設計

### 主要な設計パターン

| パターン | 原理 | 適した物語 |
|---|---|---|
| **属性型** | 火・水・風・土・光・闇。適性がある | 最も標準的。相性の駆け引きが作れる |
| **詠唱型** | 呪文の詠唱が必要。無詠唱が上級技術 | 「詠唱を省略できる」ことが強さの指標になる |
| **魔力量型** | 保有魔力の多寡が全て | 単純。インフレしやすい |
| **理論型** | 物理法則に近い規則があり、応用が可能 | 知的な面白さ。作者の設計負荷が高い |
| **契約型** | 精霊・神・悪魔との契約による | 関係性の物語になる |
| **代償型** | 使用に代償を要する（寿命、記憶、血） | 緊張が生まれる。乱用を防げる |
| **技術型** | 魔道具、魔法陣として工学化されている | 内政・産業ものと相性抜群 |
| **信仰型** | 神への信仰が力の源。教会が管理 | 政治・社会構造と直結する |

### 設計の三原則

**原則1：できないことを決める。**
魔法の設計とは、実は**制約の設計**である。「何ができるか」より「何ができないか」が物語を作る。蘇生ができないなら死に意味が生まれる。転送ができないなら旅に意味が生まれる。

**原則2：社会への影響を考える。**
生活魔法（火をつける、水を出す、洗浄する）が一般的なら、その社会に薪売りや水売りはいない。治癒魔法があるなら、医者の地位と戦争の形が変わる。**魔法は技術であり、技術は社会を規定する**。この一貫性が「作り込まれた世界」という印象を生む。

**原則3：主人公の強さと接続する。**
主人公が特別である理由が魔法体系のなかに位置づけられていると、チートが「世界の必然」に見える。「誰も気づかなかった原理を主人公だけが理解している」という構造は、外れスキルの魔法版として非常に有効である。

## 7-6　種族・国家・宗教

### 種族設計

標準的な種族（エルフ、ドワーフ、獣人、竜人、魔族）を使う場合でも、**一点だけ独自の解釈を加える**と印象が変わる。

- エルフが長命ゆえに人間社会と時間感覚がずれる（世代の断絶）
- ドワーフの鍛冶が宗教的な意味を持つ
- 獣人の身体能力が、社会的には「労働力」として搾取されている
- 竜人が絶滅危惧種であり、保護と管理の対象になっている

**種族設定は差別・格差の主題と直結する**。多くの作品で亜人差別が扱われるのは、主人公が現代倫理を発揮する舞台として便利だからである（→第5章5-5）。ただし、その扱いには注意が必要で、現実の差別問題の安易な比喩として使うと、批判の対象になりうる。

### 国家と政治

物語のスケールに応じて必要な深度が変わる。目安として、

| 物語の規模 | 必要な国家設定 |
|---|---|
| 一つの街の話 | 領主と、その上に王がいる程度 |
| 国内を旅する | 主要都市、地方の特色、貴族の勢力図 |
| 国家間の話 | 3〜5カ国の関係、対立軸、経済的な依存関係 |
| 世界規模 | 大陸構成、歴史、宗教圏、過去の大戦 |

**過剰な設定は害になる**。読者が覚えられる固有名詞には上限がある。目安として、**同時に登場する国名は3つまで、貴族家は5家まで**が読者の記憶の限界に近い。

### 宗教

異世界における宗教は、四つの機能を持つ。

1. **治癒の供給**（教会＝医療機関）
2. **社会福祉**（孤児院、救貧）
3. **政治権力**（王権との緊張関係）
4. **世界の真実の管理**（神話が実は事実である、という展開の受け皿）

とくに④は、長期連載の終盤で「世界の秘密」を明かす際の重要な布石になる。序盤で語られた神話が、終盤で事実だと判明する――この構造は非常に強い。

## 7-7　言語・文化・生活

### 言語問題

異世界で日本語が通じる理由は、次のいずれかで処理される。

| 処理 | 特徴 |
|---|---|
| 神の加護／転生特典 | 最も手軽。追及されない |
| 翻訳スキル | ゲーム的に処理。文字は読めない、という差をつけられる |
| 現地で学習する | リアル。ただし序盤が遅くなる |
| 実は日本語由来の世界 | 過去の転移者が広めた、という設定。伏線に使える |
| 説明しない | 意外に多い。読者も気にしない |

**技法上の要点**：「話せるが文字は読めない」という設定は使い勝手がよい。識字が身分の指標になり、主人公が学ぶ動機が生まれ、文書をめぐる展開が作れる。

### 食文化

異世界グルメは一大ジャンルである。ここで働いている構造は明快で、

```
①異世界の食は素朴／貧しいと設定する
②主人公が現代の調理法・調味料をもたらす
③周囲が感動する（＝観測者による承認）
```

醤油・味噌・出汁・マヨネーズ・砂糖・香辛料が「発見」される話は膨大にある。**この構造の要点は、料理そのものではなく「未知の美味に人が反応する瞬間」**にある。

### 衛生・医療

風呂、石鹸、トイレ、上下水道、消毒、麻酔――これらは内政チートの定番であり、同時に**現代人の主人公が異世界で最初に困ること**でもある。生活の不便を具体的に書くと、異世界が「絵」ではなく「場所」になる。

### 交通と通信

- 徒歩、馬、馬車。都市間の移動に数日〜数週間かかる
- 情報伝達は伝令、手紙、伝書鳩、または魔道具
- **移動と通信の遅さが、物語の緊張を作る**。転移魔法や通信魔道具を安易に出すと、この緊張が消える

### 情報環境

近年の作品では、「掲示板」「配信」「新聞」「情報ギルド」など、**情報の流通経路を設計する**作品が増えた。主人公の評判がどう広がるかは、承認エンジンの効率に直結する。

## 7-8　現代ダンジョンものの設定作法

2020年代に台頭した現代ダンジョンものは、異世界ものとは異なる設定課題を持つ。

**必須の設計項目**

| 項目 | 問い |
|---|---|
| 出現の経緯 | いつ、どこに、どうやってダンジョンが現れたか |
| 法的地位 | 誰が管理するか。国、自衛隊、警察、民間企業、国際機関 |
| 探索者の資格 | 免許制か。年齢制限は。試験は |
| 経済 | ドロップ品の売買市場。税制。企業の参入 |
| 社会的認知 | 探索者は英雄か、危険な荒くれ者か、芸能人か |
| 報道とSNS | 実力がどう可視化されるか |
| 死亡と保険 | 危険業務としての制度設計 |
| 学校・教育 | 探索者育成の教育機関はあるか |

**この設定群の物語的な価値**は、「現代社会の制度を通じて主人公の成功が可視化される」点にある。ランキング発表、報道、SNSのトレンド、企業からのスカウト――**承認の供給経路が現代的にリアル**であることが、このジャンルの最大の武器である。

## 7-9　設定のコストとリターン ―― 「説明しない技術」

### 設定作業の逆説

熱心に世界を作り込んだ作品が、必ずしも読まれるわけではない。むしろ、**設定を書きたい欲求は、物語の最大の敵になりうる**。

理由は単純で、読者は設定を読みに来ているのではなく、**物語を体験しに来ている**からである。

### 三分法

設定は、次の三つに分類して扱うのが実務的である。

| 分類 | 扱い | 割合の目安 |
|---|---|---|
| **見せる設定** | 本文中で描写・言及される | 全設定の1〜2割 |
| **効かせる設定** | 直接書かないが、登場人物の行動や描写に反映される | 5〜6割 |
| **持つだけの設定** | 作者だけが知っている。矛盾を防ぐ土台 | 2〜3割 |

多くの初心者は、この比率を逆にする。作った設定を全部書こうとして、物語が止まる。

### 設定を「効かせる」技法

書かずに伝えるための具体的な方法：

1. **人物の反応で示す**――「彼女は獣人だと知って、露骨に顔をしかめた」（差別の存在を一行で）
2. **価格で示す**――「塩が金貨一枚だと聞いて、彼は息を呑んだ」（流通と経済状況が伝わる）
3. **習慣で示す**――「食事の前に、彼らは必ず皿を三度叩いた」（宗教と文化の存在）
4. **禁止で示す**――「北の森には、誰も近づかない」（歴史と恐怖の存在）
5. **言い回しで示す**――「あなた、まさか『竜暦』で数えているの？」（複数の暦＝複数の文化圏）

いずれも、説明ではなく**具体的な事物・行動**によって背景を暗示している。

### 「設定を出す場所」の原則

> **設定は、それが必要になった瞬間に、必要な分だけ出す。**

主人公が街に入るまで、街の説明はしない。魔法を使うまで、魔法体系の説明はしない。読者は、目の前で使われているものについてなら、説明を読んでくれる。使われていないものの説明は読まれない。

## 7-10　世界設定チェックリスト

**最低限（どんな作品でも必要）**

- [ ] 文明水準（何ができて、何ができないか）
- [ ] 主人公が生きる街と、その周辺
- [ ] 貨幣と物価（A4一枚の表）
- [ ] 魔法の「できないこと」
- [ ] 危険の所在（魔物、盗賊、政治、飢餓）

**物語が広がったら**

- [ ] 国家の勢力図（3カ国程度）
- [ ] 身分制度と、その例外
- [ ] 宗教と、その社会的機能
- [ ] 種族と、その社会的位置
- [ ] 情報の伝達経路

**深めたい場合**

- [ ] 歴史（少なくとも「前の時代に何が終わったか」）
- [ ] 技術水準の内訳（冶金、農業、建築、医療をばらして考える）
- [ ] 教育と識字率
- [ ] 交易路と、それが生む都市の性格
- [ ] 世界の秘密（終盤で明かすもの）

**やってはいけないこと**

- [ ] 作った設定を全部書く
- [ ] 物語の必要がない設定を先に作り込む
- [ ] 同時に登場する固有名詞を増やしすぎる
- [ ] 主人公の便利のために設定を後から変える（読者は覚えている）
