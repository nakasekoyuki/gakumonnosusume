# 第6章　関係性の設計 ―― ヒロイン・仲間・敵役

> **本章の要点**
> WEB小説の登場人物は、外見や性格ではなく、**物語内で果たす機能**によって定義されている。「幼馴染」「奴隷」「聖女」「追放したパーティリーダー」といった類型名は、実は職能名である。本章では主要な人物類型を機能から分類し、それぞれが何を供給し、どんな失敗をしやすいかを整理する。

---

## 6-1　キャラクターは「機能の束」である

### 六つの基本機能

主人公以外の登場人物は、次の六つの機能のいずれか（または複数）を担っている。

| 機能 | 内容 | 典型的な担い手 |
|---|---|---|
| **①観測者** | 主人公のすごさに驚き、読者の代わりに評価する | ギルド職員、通行人、敵、仲間 |
| **②供給者** | 主人公に情報・資源・依頼・機会を与える | 商人、師匠、王族、ギルドマスター |
| **③受益者** | 主人公に救われ、感謝し、忠誠を返す | 奴隷、助けた村人、拾った子ども |
| **④鏡** | 主人公の内面を引き出す。会話の相手 | 幼馴染、相棒、従魔 |
| **⑤障害** | 主人公の前に立ちはだかる | 敵、ライバル、制度、身内 |
| **⑥報酬** | 主人公が獲得するもの（関係・愛情・信頼） | ヒロイン、仲間、家族 |

この分類の実用性は、**キャラクターが機能していないときに、どこが空いているかを診断できる**点にある。

- 主人公のすごさが伝わらない → **観測者が不足**している
- 物語が停滞する → **供給者**が新しい課題を持ってこない
- 主人公の内面が見えない → **鏡**がいない
- 緊張がない → **障害**が弱い

### 「観測者」の重要性

WEB小説においてもっとも過小評価されている役職が、**観測者**である。

主人公が強いことを、主人公自身が語っても読者は興奮しない。**他者が驚愕することで初めて、強さは価値になる**。だからWEB小説には、ギルドの受付嬢、酒場の冒険者たち、貴族の従者、敵の幹部といった「驚く係」が大量に配置される。

観測者の設計原則：

1. **観測者には、驚くための前提知識を持たせる**――何がどれくらいすごいかを判断できる立場（ベテラン冒険者、鑑定持ち、貴族）
2. **観測者の評価は、段階的に更新させる**――「まあまあだな」→「待て、これは」→「ありえない」
3. **観測者を使い捨てにしない**――繰り返し登場する観測者がいると、関係が育つ
4. **視点を貸す**――他者視点の挿話は、観測を最大化する技法である

## 6-2　ヒロイン類型カタログ（男性向け作品）

以下、頻出する類型を、**供給する感情**と**構造上の役割**で整理する。

### ① 奴隷・被救済者
主人公が買う、または助けることで関係が始まる。獣人、エルフ、亜人であることが多い。
- **供給する感情**：無条件の信頼、感謝、依存
- **役割**：受益者＋鏡。序盤の相棒として、主人公の内面を引き出す
- **注意**：奴隷制を使う以上、**主人公の倫理的立場をどう扱うか**を避けられない。「買って即解放するが本人が離れない」というパターンが多用されるが、これは倫理的な回避策であると同時に、批評的には論点をずらしているという指摘もある

### ② 幼馴染・許婚
異世界内の関係として最初から存在する。
- **供給する感情**：安定、既知の関係、遠慮のなさ
- **役割**：鏡。主人公の素の会話相手
- **注意**：ハーレム作品では「敗北しやすい枠」として類型化されており、読者の期待が既に定まっている

### ③ 高貴な女性（王女・令嬢・聖女）
身分が高く、主人公を政治的・社会的に引き上げる。
- **供給する感情**：格の上昇、承認
- **役割**：供給者＋報酬。物語のスケールを拡大する装置
- **注意**：身分差の障害をどう処理するかが構成上の課題

### ④ 女騎士・武人
戦闘能力があり、主人公と対等に戦える。
- **供給する感情**：尊敬される快感、対等な信頼
- **役割**：観測者（実力がわかる立場）＋仲間
- **注意**：主人公が圧倒的だと、存在意義が薄れる。**役割の分業**（前衛と後衛、武と知）を明確にすること

### ⑤ 精霊・神獣・従魔
人ならざる存在。契約や絆で結ばれる。
- **供給する感情**：特別性、無条件の愛着
- **役割**：報酬＋能力の拡張
- **注意**：しゃべるか否かで作品の性格が変わる。しゃべると相棒、しゃべらないとペット

### ⑥ ロリババア・長命種
外見は幼く、実年齢は数百歳。
- **供給する感情**：知識、達観、ギャップ
- **役割**：供給者（歴史・古代知識）＋鏡
- **注意**：世界の歴史を語らせる装置として非常に便利だが、便利すぎて説明係になりやすい

### ⑦ 商人・職人・薬師
非戦闘の専門職。
- **供給する感情**：現実的な有能さ
- **役割**：供給者。経済・生産ラインを担う
- **注意**：内政・経営ものでは主人公以上に重要になりうる

### ⑧ 敵からの転向者
かつて敵だった者が仲間になる。
- **供給する感情**：赦しと再生、獲得の実感
- **役割**：観測者（かつて敵として主人公を測った）＋報酬
- **注意**：転向の説得力。**主人公の何に負けたのか**を明確に

### ⑨ 天然・ポンコツ
能力は高いが日常生活が壊滅的、あるいは常識がない。
- **供給する感情**：笑い、庇護欲
- **役割**：コメディの供給源
- **注意**：ポンコツさが物語の障害になりすぎると苛立ちを生む

### ⑩ 姉・母・保護者型
主人公を庇護する年上の女性。
- **供給する感情**：受容、安心
- **役割**：報酬＋供給者
- **注意**：主人公が最強だと、庇護の必要がなくなり関係が変質する

## 6-3　攻略対象・相手役の類型（女性向け作品）

女性向けでは、相手役の設計原理が異なる。**「どんな人か」よりも「ヒロインをどう扱うか」**が類型の軸になる。

| 類型 | 特徴 | 供給する感情 |
|---|---|---|
| **冷徹だがヒロインにだけ甘い** | 対外的には氷、内側では溺愛 | 選ばれた特別性 |
| **執着・独占型** | 過剰な愛情。理由は後半で明かされる | 絶対的な受容 |
| **不器用・無自覚型** | 好意を伝えられない。誤解を生む | じれったさと解消 |
| **有能な理解者** | ヒロインの能力を正当に評価する | 承認、対等な信頼 |
| **年上・庇護型** | 経験と余裕でヒロインを守る | 安心 |
| **年下・献身型** | まっすぐな好意を向ける | 慕われる快感 |
| **敵対から転じる型** | 誤解や立場で対立し、和解する | 関係の逆転 |
| **契約相手** | 利害で結ばれ、情が生まれる | 変化の物語 |
| **獣人・人外** | 種族的な一途さ | 本能的な選択の絶対性 |

### 女性向けにおける「元婚約者」の機能

女性向け作品にはほぼ必ず登場する「**元婚約者（あるいは元家族）**」は、次の三つの機能を同時に果たす。

1. **加害者**――冒頭の不当な扱いを実行する
2. **比較対象**――新しい相手役の良さを引き立てる
3. **ざまぁの受け手**――後半で報いを受ける

つまり、元婚約者は「捨てるために存在する人物」である。だが優れた作品では、彼にも一定の論理と事情が与えられ、それによってざまぁのカタルシスが深まる。**単なる愚か者にすると、ヒロインが愚か者に騙されていたことになり、ヒロインの評価まで下がる**――これは実務上、非常に重要な注意点である。

## 6-4　ハーレム構造の力学

### なぜハーレムなのか

複数のヒロインが主人公に好意を寄せる構造は、しばしば批判される。だが機能的に見ると、これは**承認エンジンの並列化**である。

- ヒロインが1人なら、承認は1系統しか供給されない
- ヒロインが5人なら、5種類の異なる形の承認が供給される（尊敬、依存、対等、庇護、憧憬）
- しかも、それぞれが独立して継続的に作動する

つまりハーレムは、恋愛の多重化ではなく、**承認供給の冗長化**である。

### 三つの管理課題

**課題1：嫉妬の管理**
ヒロイン同士が争うと、読者にストレスを与える。解決策として類型化されているのは、

| 解法 | 内容 |
|---|---|
| 序列の明示 | 「正妻」が確定していて、他は納得している |
| 役割の分業 | 恋愛枠、家族枠、戦友枠と関係の質を分ける |
| 全員が友好 | ヒロイン同士が仲良く、共闘関係にある |
| 主人公の鈍感 | そもそも恋愛関係が進行しない（緊張の凍結） |
| 文化的正当化 | 一夫多妻が世界設定として当然 |

**課題2：出番の配分**
登場しないヒロインは読者の記憶から消える。5人以上のヒロインを維持するには、章ごとに主役を回すなどの計画が要る。**実務的には、常時稼働のヒロインは3人程度が上限**である。

**課題3：関係の終着点**
関係を進展させれば緊張が失われ、進展させなければ苛立ちを生む。多くの作品が「進展させない」ことを選ぶが、これが「主人公が鈍感すぎる」という不満の原因になる。

> **代替案としての「一途もの」**
> 近年、ヒロインを1人に絞る作品も安定した支持を得ている。承認の量では劣るが、**関係の深度**で勝負できる。ハーレムか一途かは、作品が「量的な承認」と「質的な関係」のどちらを売るかの選択である。

## 6-5　仲間・パーティの設計

### 役割分業の設計

パーティものでは、**機能が重複しないこと**が設計の基本である。

| 軸 | 分業の例 |
|---|---|
| 戦闘 | 前衛／後衛／回復／索敵 |
| 知識 | 世界の歴史／魔法理論／裏社会／貴族社会 |
| 性格 | 常識人／暴走役／冷静／甘え役 |
| 対社会 | 交渉／実務／情報／腕力 |

**重要な原則**：主人公が最強である作品では、仲間は「戦力」としては不要になる。したがって仲間の存在意義を、**戦闘以外**に置く必要がある。

- 主人公にできないこと（社交、事務、料理、交渉）を担う
- 主人公が守るべき対象として、緊張を生む
- 主人公の内面を引き出す（鏡）
- 読者の代わりに驚く（観測者）

『この素晴らしい世界に祝福を！』のパーティが機能しているのは、**全員が戦力として欠陥を抱えているが、コメディの供給者として完璧**だからである。役割は戦闘に限らない。

### 仲間が増え続ける構造への対処

WEB小説では仲間が際限なく増えがちである。対処法として、

1. **階層化する**――中核メンバー（常時登場）と外周メンバー（必要時のみ）を分ける
2. **拠点に置く**――拠点で待つ役割にして、出番を制御する
3. **組織化する**――個人ではなく部隊・商会・領民として扱い、集合的に描く
4. **視点を与えない**――視点人物を増やさなければ、読者の認知負荷は上がらない

## 6-6　敵役の類型と機能

敵役は「障害」機能を担うが、その形はさまざまである。

### ① 侮る者（かませ）
主人公を過小評価し、返り討ちにあう。
- **機能**：ざまぁの供給、格の証明
- **注意**：**弱すぎると主人公の格も上がらない**。かませには一定の実力と評判を与えること。「Aランク冒険者が全く歯が立たない」という構図でこそ主人公が輝く

### ② 腐敗した権力者（悪徳貴族・悪徳商人・堕落した教会）
制度的な悪。
- **機能**：社会的な障害。倒すことで主人公が公的な評価を得る
- **注意**：単純な悪にすると世界が薄っぺらくなる。**その人物が腐敗した構造的な理由**を一行でも書くと厚みが出る

### ③ 元の仲間・追放した側
かつて主人公を貶めた者。
- **機能**：ざまぁの受け手
- **注意**：後述（6-7）

### ④ 対等なライバル
主人公と同格。互いに認め合う。
- **機能**：緊張の維持、成長の指標
- **注意**：主人公最強ものでは成立が難しい。**別種の強さ**（速度、知略、権力）を持たせるのが定石

### ⑤ 魔王・世界の敵
最終的な脅威。
- **機能**：物語の終点を設定する
- **注意**：出すと物語の終わりが見えてしまう。近年は**魔王を出さない、あるいは味方にする**作品も多い

### ⑥ 別の転生者・転移者
主人公と同じ資格を持つ他者。
- **機能**：主人公の選択の正当性を対比で示す。倫理的なテーマを導入できる
- **注意**：非常に強力な装置。転生者が悪事を働くとき、主人公は「同じ立場でありながら違う選択をした者」として輝く

### ⑦ 制度・慣習・自然
人格を持たない障害。身分制度、飢饉、疫病、魔物の氾濫。
- **機能**：主人公の力の質を変える。戦闘以外の解決を要求する
- **注意**：内政もの・生産ものの主敵。**インフレを起こさない障害**として非常に有用

### ⑧ 主人公の内面
過去、トラウマ、欲望、限界。
- **機能**：唯一、力で解決できない障害
- **注意**：これを扱える作品が、長く記憶される（→第5章5-7）

## 6-7　「かませ」と溜飲下げの倫理

WEB小説批判のもっとも一般的な標的が、「**敵が愚かすぎる**」という点である。この批判は、多くの場合正しい。

だが、なぜ敵は愚かに書かれるのか。構造的な理由がある。

```
主人公の格を上げる最短の方法は、相手の格を下げることである。
```

これは短期的には有効だが、長期的には作品全体の価値を毀損する。**主人公が乗り越えた障害の大きさが、主人公の価値の上限を決める**からだ。愚かな敵しか倒していない主人公は、愚かな敵を倒せる程度の存在にしか見えない。

### 実務的な処方箋

| 悪い設計 | 良い設計 |
|---|---|
| 敵が理由なく主人公を憎む | 敵には、その立場なりの合理性がある |
| 敵が主人公の実力を全く見抜けない | 敵は見抜くが、それでも別の理由で敵対する |
| 敵が一方的に喋って自滅する | 敵の主張には一定の説得力がある |
| 敵が最後まで反省しない | 敵が自分の誤りを理解する（＝ざまぁの最大化） |

とくに最後の点は重要である。**ざまぁの快楽の頂点は、加害者が「自分が何を失ったか」を正確に理解する瞬間**にある。理解できない愚か者は、ざまぁの対象としてすら不十分である。

## 6-8　その他の重要な役職

### 師匠
主人公に技術と世界観を教える。**説明の正当化装置**として非常に有用。ただし主人公が最強になると不要になるため、多くの作品で「途中で退場する」「実は主人公のほうが強かった」という処理を受ける。

### 家族
異世界での家族は、**主人公を世界に接続する**役割を持つ。転生ものにおいて、家族の存在は「異世界が仮初めではない」ことの保証になる。『無職転生』の家族描写が作品の核心を成しているのは偶然ではない。

### 部下・従者
主人公が組織を持つ段階で登場。**主人公の指示を実行し、その効果を報告する**ことで、主人公の影響力を可視化する。内政ものでは必須。

### 子ども・幼獣
保護対象。**主人公の優しさを行動で示す装置**であり、近年の癒し系需要の中核。成長を描けば長期の物語になる。

### 神・女神・システム
物語の外部から介入する存在。**説明できないことを説明する装置**として便利だが、多用すると世界の必然性が失われる。「困ったら神様が助けてくれる」構造は、緊張を根本から破壊する。

## 6-9　関係性そのものがジャンルになる領域

### BL（ボーイズラブ）
男性同士の関係を主題とする。pixiv、ムーンライト、エブリスタ等が主戦場。異世界転生との結合（悪役令息もの、モブ転生もの）が2010年代後半から活発。**関係の非対称性と、それが解消される過程**が快楽の中心。

### 百合・GL
女性同士の関係。2010年代後半から異世界ものとの結合が進み、『転生王女と天才令嬢の魔法革命』などが牽引した。**対等性と共闘**が快楽の中心にあるのが、BLとの構造的な差異である。

### TL（ティーンズラブ）／女性向けR18
恋愛の身体的側面を主題化する。ムーンライトノベルズが主要な供給源で、書籍化市場も大きい。**溺愛・執着の類型は、この領域で最も濃く発展した**。

これらの領域は、しばしば「一般向け」の分析から除外されるが、**関係性の設計技術という点では、むしろ最先端**である。関係の段階、距離の詰め方、感情の言語化――男性向け作品が苦手とする領域の技術が蓄積されている。
